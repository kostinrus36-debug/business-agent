### А-b. (опционально, новое) — Etsy Seller App API вместо ручных кликов
1. etsy.com/developers/register → зарегистрируй приложение типа "Seller
   App" (одобрение автоматическое, минуты).
2. Скопируй API keystring в Developer Portal.
3. Пройди OAuth-авторизацию в браузере (не пароль).
4. В меню облачной среды Claude Code добавь `ETSY_API_KEYSTRING`,
   `ETSY_ACCESS_TOKEN` (и `ETSY_REFRESH_TOKEN`, если покажется) — только
   в поле формы среды, не в чат.
5. В Network access добавь `api.etsy.com`.
6. Сообщи в следующий прогон — агент сначала опубликует 1 листинг, потом
   остальные после подтверждения.
