### Новое: пункт 4-b (опционально) — Printify API вместо ручных кликов
**Зачем:** пункт 4 (публикация 5 дизайнов) не выполняется 15 прогонов
подряд — не из-за неготовности материала, а из-за нехватки времени на
клики в будни. Это разовая настройка, которая уберёт эту зависимость для
всех будущих публикаций (не ускоряет сегодняшние 5 дизайнов — если проще
кликнуть вручную сейчас, делай так и пропусти этот пункт).
**Шаги:**
1. Открой https://developers.printify.com/ → войди под своим Printify-
   аккаунтом → "Authentication" → "Create a personal access token" →
   назови токен, выбери scope products+shops, скопируй значение.
2. Открой меню облачной среды Claude Code → Edit → API credentials/
   Environment variables → добавь переменную `PRINTIFY_API_TOKEN` со
   значением токена. **Не пиши токен в чат — только в это поле формы.**
3. В том же меню (Network access) добавь `api.printify.com` и
   `developers.printify.com` в разрешённые домены (или выбери более
   широкий уровень доступа).
4. Сообщи в следующий прогон, что готово — агент проверит доступ,
   опубликует сначала только Kalymnos, покажет результат до публикации
   остальных 4.
**Пароли/аккаунты:** токен не пароль, хранится вне репозитория.
**Время:** ~10-15 минут разово. **Деньги:** €0.

Остальные пункты (А, 0, 1, 2, 3, 4, 5) без изменений — полные тексты и
шаги в PORTFOLIO.md.
