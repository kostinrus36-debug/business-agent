## Стратегия портфеля (обновлено 2026-08-10)
Кейсы 2-4 намеренно выбраны в той же нише (скалолазание/DACH), что и
кейс 1 — переиспользуем уже существующую аудиторию (Instagram-трафик,
Etsy-витрину, бренд ROUTELINEWEAR) вместо построения новой аудитории с
нуля для каждого кейса. Инструмент (кейс 4) и контент (кейс 3) деплоятся
вместе через один автоматический workflow — взаимные ссылки между всеми
четырьмя кейсами усиливают друг друга, и теперь с UTM-метками это будет
измеримо, а не только предположительно.

Ротация/масштаб: сейчас рано закрывать или укрупнять что-либо — проекту
1-2 дня, ни у одного кейса ещё нет ни одной недели без прогресса (нужно
3 подряд, см. устав), и ни один цифровой кейс (2-4) ещё не задеплоен, то
есть реального рыночного сигнала для решения "куда концентрировать фокус"
пока физически нет. Первая содержательная ревизия имеет смысл не раньше
появления первых метрик после деплоя — не начало сентября механически,
а когда будут данные.

или заменяются новыми идеями. Проект стартовал 2026-08-09 — ни один кейс

деплоя кейсов 3-4 и публикации листингов кейса 2, а не по календарной
дате механически.
