| **Реальные продажи** | Таблица `deals` — 0 строк, но никогда не сверялась с реальным кабинетом AliExpress Affiliate — статус неизвестен, не подтверждённый ноль |
| **Реальный охват** | Buffer API (владелец, 2026-08-22): 0-7 просмотров/пост за 7 дней — не "мало", фактически нулевой трафик |

**2026-08-28:** Владелец напрямую сверил рекомендацию "дешёвые находки
€3-20" с реальными цифрами (охват Buffer + комиссия AliExpress) и
попросил пересчитать вывод — сделано (роли Финансы+Рынок+Маркетинг, см.
plan.md). **Пересчёт:** при охвате 0-7 просмотров/пост ценовой сегмент
арифметически не может быть решающим фактором — P(продажа) слишком
близко к нулю в обоих случаях, разница в комиссии (до 10-15x) умножается
на почти-ноль. Более вероятная первопричина самого нулевого охвата —
не цена, а то, что 100% контента TrendPin рекламный без полезной
примеси: по 2 независимым источникам Pinterest алгоритмически занижает
охват именно таких аккаунтов (правило 80/20). Пересмотренный план: не
сужать ценовой фильтр, а расширить (`MIN_PRICE=3, MAX_PRICE=150`, чтобы
воркфлоу вообще начал находить товары) и параллельно разбавить поток
пинов 20% полезного контента без ссылки (см. IDEA-BACKLOG.md, идея №4)
— это диагностирует и чинит вероятный корень проблемы, а не спорит о
цене без данных о реальной конверсии. Пакет одобрения (п.0 ниже)
переписан под этот план.

etsy.com/ebay.de по-прежнему заблокированы прокси этой среды, без

наблюдения (правило BRAIN.md "не тратить токены впустую"):** 15 прогонов
подряд один и тот же затор — не нехватка готового материала (тексты/цены/

**Честно:** это не ускоряет публикацию именно текущих 5 дизайнов (сетап

из-за неготовности материала, а из-за нехватки времени владельца на клики
в чужом кабинете в будни. Это разовая настройка (не публикация как
таковая), которая позволит агенту публиковать этот и будущие дизайны
через API Printify самостоятельно — подробный разбор, включая явную
проверку роли Финансы/право/совесть на соответствие жёстким границам
CHARTER.md (Personal Access Token — не пароль, хранится только как
секрет окружения, не в репозитории), см.
[audit.md, п.8.7](cases/gewerbe-trading/audit.md).
**Честно:** не ускоряет публикацию именно этих 5 дизайнов сегодня (сетап
токена+сети — тоже время владельца), окупается на масштабе после первого
раза. Если проще один раз кликнуть по пункту 4 вручную — делай так,
этот пункт можно пропустить.
**Шаги:**
1. Открой https://developers.printify.com/ → войди под своим Printify-
   аккаунтом → "Authentication" → "Create a personal access token" →
   назови токен, выбери scope products+shops, скопируй значение (покажется
   один раз).
2. Открой меню облачной среды Claude Code (там же, где настроен этот
   рутин) → Edit → раздел API credentials/Environment variables → добавь
   переменную `PRINTIFY_API_TOKEN` со значением токена. **Не вставляй
   токен в чат/сообщение агенту — только в это поле формы среды.**
3. В том же меню (Network access) добавь в разрешённые домены
   `api.printify.com` и `developers.printify.com`, либо выбери более
   широкий уровень доступа.
4. Сообщи в следующий прогон, что готово — агент проверит доступ и, если
   сработает, сначала опубликует только Kalymnos, покажет результат в
   отчёте, и только потом (по подтверждению, что всё в порядке —
   eBay.de, не eBay.com) опубликует остальные 4.
**Пароли/аккаунты:** не требуется новый аккаунт — токен не пароль,
хранится вне репозитория. **Время:** ~10-15 минут разово. **Деньги:** €0.

### 5. Кейс Б — проверка боли с реальными строителями
**Зачем:** единственный блокер перед MVP — нужно подтвердить, что
проблема (Nachtrag-документация) реально болит у 5-10 знакомых
строителей.
**Шаги:**
1. Открой [validation-interview-kit.md](cases/micro-saas/validation-interview-kit.md)
   — там готовое сообщение для контактов и 12 вопросов на немецком.
2. Отправь сообщение 5-10 знакомым из отрасли (WhatsApp/личный контакт).
3. Запиши ответы прямо в файл или перескажи мозгу в следующем прогоне —
   он сам решит, сигнал это или тревожный звоночек.
**Время:** зависит от ответов контактов, не от тебя — можно растянуть на
пару недель.
