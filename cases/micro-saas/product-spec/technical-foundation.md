# Техническая основа сметного приложения — стандарты и логика

Статус: живой документ, обновляется ежедневно (см. правило внизу). Не
черновик "на отвали" — каждое решение должно быть обосновано, не просто
"звучит логично".

---

## Зачем эта основа

Чтобы "умные подсказки" (сказал "шпаклёвка" — приложение предлагает
шлифовку/грунтовку/класс качества/кол-во слоёв) звучали профессионально
для реального мастера, а не как самодельный список. Всё завязано на
реальных немецких стандартах (VOB/C, DIN, VDE), не придумано с нуля.

## Общий костяк каталога работ

Немецкая стройотрасль уже имеет стандартизированный каталог позиций —
**StLB-Bau** (Standardleistungsbuch für das Bauwesen), ведёт GAEB
(Gemeinsamer Ausschuss Elektronik im Bauwesen) совместно с DIN, формат
обмена — **GAEB DA XML** (X83 — LV для подрядчика, X84 — оценённое
предложение обратно). Все серьёзные немецкие сметные программы (STREIT,
HERO, Hawepro, Baufaktura) строят импорт/экспорт GAEB как базовую
функцию — **наше приложение должно сопоставлять позиции с кодами
StLB-Bau/GAEB**, не изобретать свою таксономию — иначе выглядит
непрофессионально для мастера, который уже знает эту систему.

## Технологическая последовательность работ (критично, владелец 2026-08-13)

Подсказки — это не просто "плоский список сопутствующих позиций", а
**обязательная технологическая последовательность**, которую нельзя
нарушать. Примеры от владельца (реальный опыт):
- **Перед шпаклёвкой — грунтовка** (не после, не одновременно)
- **Перед покраской — грунтовка** (отдельный слой, своя грунтовка под
  тип краски)
- Плитка/ступени/брусчатка — у каждого материала своя технологическая
  цепочка (основание → гидроизоляция при необходимости → клеевой
  состав → укладка → затирка), нарушение порядка = брак, который
  вскроется позже и станет источником спора с заказчиком

**Значит для продукта**: система подсказок должна знать не только "что
обычно идёт вместе" (шлифовка+грунтовка+класс качества), но и **в каком
порядке**, и не давать зафиксировать в документе технологически
неправильную последовательность (или хотя бы явно предупреждать). Это
отдельный уровень логики поверх простого автодополнения — граф
зависимостей операций по каждому виду работ, не плоский список. Требует
отдельной проработки по каждой специализации (грунтовка-перед-Х
встречается у минимум 4 из уже расписанных: шпаклёвка, покраска, плитка,
некоторые виды стяжки).

### Первые два конкретных графа (штукатурка, плитка) — проработано 2026-08-13

Ниже — не абстракция, а конкретная последовательность с указанием, **что
ломается**, если шаг пропущен или переставлен. Это тот вид детализации,
который приложение должно уметь показать мастеру как чек-лист/gate, а не
просто список позиций для цены.

**Штукатурка (Putz), стандартная стена без особых проблем с влагой:**
1. Проверка/подготовка основания (Untergrundprüfung) — впитывающая
   способность, прочность, отсутствие пыли/разделительных veществ.
2. При необходимости — **Vorspritzer/Spritzbewurf** (сцепляющий
   набрызг) — обязателен на гладких/слабовпитывающих основаниях
   (например бетон). Пропуск = отслоение штукатурки позже (Hohlstellen,
   Abplatzen) — типичный источник рекламации через несколько месяцев,
   когда причина уже не видна визуально.
3. **Grundputz/Unterputz** (базовый слой) — группа раствора по толщине и
   зоне (см. ниже).
4. Время высыхания/твердения ДО следующего слоя — эмпирическое правило
   отрасли "~1 день на 1 мм толщины" встречается в источниках как
   практическое правило, а не жёсткая норма DIN — **отметить как
   неподтверждённое численно, требует проверки по DIN 18550-1** при
   следующей ревизии.
5. **Oberputz/Deckputz** (финишный слой) — только после п.4.
6. Опционально — окраска/покрытие (см. Maler-раздел, приоритет на
   ближайшую ревизию, ещё не расписан подробно).

Если основание влажное и/или засолено (частый случай в реновации Altbau в
Германии) — между п.1 и п.3 обязательна отдельная ветка: диагностика
влажности/причины/степени засоления → выбор **WTA-Sanierputzsystem**
(WTA-Merkblatt 2-9-20/D) вместо обычного Kalkzementputz — обычный раствор
на солёном/сыром основании **не держится долго и является техническим
браком по правилам отрасли**, а не просто "хуже смотрится".

**Плитка внутри помещения (Fliesen, влажное помещение — ванная):**
1. Проверка основания (ровность, трещины, прочность) — DIN 18157-1
   требует основание без сквозных трещин.
2. Грунтовка/адгезионный слой по типу основания.
3. **Абдихтунг (гидроизоляция) — ДО укладки плитки, не после.** Во
   влажных помещениях — Verbundabdichtung по стандарту (актуально —
   область регулирования переходит от старого DIN 18195 к новому DIN
   18534 для внутренних помещений; отметить как открытый вопрос —
   нужно проверить, какой стандарт актуален для конкретной зоны на
   2026 год) + отраслевой ZDB-Merkblatt "Abdichtungen im Verbund mit
   Fliesen und Platten". Пропуск = протечка в конструкцию, которая
   проявится через месяцы/годы — классический источник дорогого спора,
   потому что дефект не виден в момент сдачи.
4. Выбор способа укладки — **Dünnbett** (тонкий слой клея, ~2-6 мм по
   DIN 18157) для большинства случаев, **Mittelbett** (~5-15 мм) — при
   неровном основании или тяжёлых/крупноформатных плитках.
5. **Планирование швов ДО укладки, не после**: краевой шов (Randfuge) у
   стен/жёстких конструкций — минимум 5 мм (лучше 8 мм); при площади
   помещения от ~40 м² — обязательны деформационные швы поля
   (Feldbegrenzungsfuge), поле не более ~5-8 м по стороне (ориентир по
   ZDB-Merkblatt Bewegungsfugen). Пропуск = растрескивание швов/плитки
   от температурных подвижек конструкции.
6. Укладка, выдержка перед затиркой швов, затирка, силиконовые
   примыкания по углам/стыкам с другими материалами (не жёсткая
   затирка на подвижных стыках).

**Плитка/камень снаружи (терраса, балкон, ступени) — отдельная ветка,
строже из-за мороза и воды:**
1. Проверка несущего основания + **уклон обязателен** (не опция): для
   ровных поверхностей терраса/балкон — 1-2% (ZDB-Merkblatt), **для
   ступеней — минимум 2% на каждую ступень отдельно** (ориентир по DIN
   18065 и ZTV-ING, применяется по аналогии в отраслевой практике
   уличных ступеней). Без уклона — стоячая вода → зимой лёд на
   ступенях (риск травмы + Verkehrssicherungspflicht подрядчика/
   владельца) и **отслоение/растрескивание от мороза** (замерзающая
   вода расширяется в порах материала).
2. Гидроизоляция в связке (Verbundabdichtung) — вода должна уходить из-
   под покрытия без образования подпора (гидростатического давления)
   под плиткой.
3. При недренирующем основании — дренирующий мат/слой.
4. Клей — минимум класс **C2** по DIN EN 12004 (Haftfestigkeit ≥1,0
   Н/мм²), морозостойкий/водостойкий вариант **(проверено 2026-08-14)**:
   немецкая отраслевая Flexmörtel-Richtlinie требует для улицы/террасы/
   балкона именно C2 как минимум, плюс эластичность **S1** (изгиб
   ≥2,5 мм до разрушения — компенсирует температурные подвижки уличного
   основания). Простой немодифицированный C1-клей для улицы не
   годится — это была верно предугаданная гипотеза, теперь подтверждена
   источником, не только "звучит логично".
5. Укладка с контролем уклона по каждому элементу (не только "в целом
   по террасе").
6. Деформационные швы чаще, чем внутри (сильнее перепад температур на
   улице) — точное численное правило для уличных швов сегодня НЕ
   подтверждено отдельно от внутренней нормы (см. п.5 выше про
   40 м²/5-8 м — это ориентир для помещений) — **открытый вопрос,
   нужен прямой доступ к ZDB-Merkblatt "Bewegungsfugen" для уличной
   части, следующая ревизия**.
7. Класс противоскольжения (см. отдельно ниже) выбирается по типу
   входа/ступени, не универсально.

**Покраска (Maler-/Lackierarbeit) — типовой случай ремонта поверх
существующей штукатурки/старой краски, проработано 2026-08-14:**
1. **Untergrundprüfung перед первым мазком, не после**: тип и состояние
   старого покрытия (минеральная известковая/силикатная краска vs.
   дисперсионная), впитывающая способность, меление (Kreiden — проверка
   стиранием ладонью), трещины, влажность. Это отдельная профессиональная
   обязанность маляра (Prüf- und Hinweispflicht) — если основание не
   годится под заявленный тип краски, маляр обязан предупредить клиента
   ДО начала работы, не молча красить поверх и не разбираться после
   рекламации.
2. **Совместимость систем — не декоративный вопрос, а технический
   gate**: силикатная краска требует минеральное (не запечатанное
   пластиком) основание — на дисперсионном старом слое силикатная краска
   не держится и отслаивается. Обратная ошибка чаще и опаснее: закрыть
   диффузионно-открытую известковую/силикатную Altbau-стену
   непроницаемой дисперсионной плёнкой — влага из стены не может выйти
   наружу, результат через месяцы — пузыри, отслоение, в худшем случае
   плесень внутри конструкции. Для типичного немецкого Altbau (много
   исторических известковых/силикатных оснований) это частый источник
   спора именно потому, что дефект (как и в разделе про плитку/штукатурку
   выше) не виден в день приёмки.
3. При несовместимом старом покрытии — единственный по-настоящему
   надёжный путь, а не компромисс: полное удаление старой краски и
   повторная проверка основания (впитывающая способность, pH,
   минеральность), а не "грунтовка-мостик поверх всего подряд" как
   универсальное решение.
4. Грунтовка (Grundierung/Haftgrund) — подбирается **под конкретную пару**
   основание+финишная краска, не одна универсальная грунтовка на все
   случаи (см. раздел ниже про DIN 18363/классификацию красок).
5. **Кол-во слоёв — не "на глаз", а специфицируется до начала работы.**
   Если явно не оговорено иное, ATV DIN 18363 (ред. 2019-09) по умолчанию
   требует для первой окраски минеральных оснований снаружи
   трёхслойную систему (Grund-, Zwischen-, Schlussbeschichtung) — см.
   подробности в разделе про DIN 18363 ниже. Пропуск слоя без явной
   договорённости об отступлении = недоделанная (mangelhafte) работа по
   умолчанию, а не "маляр решил, что и так достаточно".
6. Выдержка между слоями по данным производителя краски (грунтовка
   должна высохнуть до нанесения финишного слоя) — конкретные часы
   зависят от продукта, не фиксированы одним числом в DIN, поэтому
   приложение должно подсказывать "выдержать по TM листу продукта", а не
   придумывать общее число.
7. Финишное покрытие, контроль укрывистости при дневном/боковом свете
   (Streiflicht) — совпадает с логикой Q3/Q4 в гипсокартоне: дефект виден
   не при прямом, а при боковом освещении.

**Кровля скатная (Steildach), типовой случай — переукладка кровли из
черепицы/бетонной плитки с утеплением, проработано 2026-08-15:**
1. **Снятие старого покрытия открывает стропила и старую обрешётку для
   осмотра — это единственный момент, когда их вообще видно.** Проверка
   на гниль, жучок-точильщик, трещины, прогиб. **Критично для продукта**:
   само по себе обнаружение проблемы НЕ создаёт у кровельщика автоматической
   обязанности бесплатно её исправить — без отдельной договорённости или
   явного указания заказчика ремонт стропил не входит в изначальный объём
   работы по переукладке. Но кровельщик обязан заявить об этом заказчику
   (Bedenkenanmeldung/Prüf- und Hinweispflicht — тот же принцип "добросовестности
   в строительном договоре", что уже упоминался для сценария 7 про покраску,
   формально закреплён для VOB-договоров в §4 Abs.3 VOB/B и признаётся судами
   как общий принцип и для обычных BGB-Werkverträge) — **до того, как
   продолжить закрывать конструкцию новым покрытием**, иначе риск дефекта
   переходит на самого кровельщика, даже если причина (гнилые стропила) была
   не его виной. Это ровно тот момент, где приложение должно форсировать
   фото повреждения + письменную фиксацию находки + подпись/согласие клиента
   на доп. работу и её цену ДО того, как следующий слой (Unterspannbahn)
   закроет проблему навсегда — самый ценный кадр во всей фотодокументации
   объекта, не декоративный, а доказательство, которое разваливает конкретно
   тот тип спора "я не знал, что там гниль" или "это должно было входить в
   изначальную цену".
2. **Проверка фактического уклона кровли (Dachneigung) против двух порогов**:
   абсолютный минимум для штучной кровли (черепица/бетонная плитка) по
   правилам ZVDH — **10°**, ниже штучное покрытие в принципе не
   закладывается без специального решения; и **Regeldachneigung** —
   индивидуальный для конкретного продукта угол (типично 22°/25°/30°/35°/40°
   в зависимости от профиля черепицы/плитки и величины нахлёста), указанный
   производителем. Если факт. уклон ниже Regeldachneigung, но ≥10° —
   обязательны **regensichernde Zusatzmaßnahmen** по регламенту ZVDH
   ("Regeln für Dachdeckungen mit Dachziegeln und Dachsteinen" /
   "ZVDH-Regeln für Unterdeckungen und Unterspannungen") — доп. слой
   герметизации (более герметичная подкровельная плёнка/проклейка нахлёстов),
   градация по классам сложности требований. **Открытый вопрос**: точная
   таблица "класс доп.меры ↔ величина недобора уклона" сегодня не
   подтверждена по первоисточнику (страница ZVDH и профильные PDF
   недоступны напрямую через egress-прокси), взято по снипетам поиска —
   для продукта на следующей ревизии нужно свести точную таблицу, пока в
   базу типовых работ закладывается только сам факт правила ("уклон ниже
   Regeldachneigung → обязательна доп.мера, не берётся тип по умолчанию").
   **Для продукта**: это прямой источник законного, предсказуемого Nachtrag
   — маленькая бригада, которая обмеряет крышу на месте голосом/фото, должна
   получить предупреждение "уклон Х° ниже нормы для этой черепицы → нужна
   доп. позиция", а не узнать об этом после укладки.
3. При утеплении ската (Zwischensparrendämmung) — **Dampfsperre/Dampfbremse
   с внутренней стороны**, согласованная по sd-значению (сопротивление
   диффузии пара) с наружной подкровельной плёнкой по **DIN 4108-3**: для
   невентилируемой конструкции требуется, чтобы внутренний слой был
   значительно менее паропроницаем, чем наружный — ориентировочные
   табличные пары (по вторичным источникам, не проверено по тексту DIN
   напрямую — отметить как требующее сверки на следующей ревизии): при
   sd наружного слоя ≤0,1 м внутренний должен быть ≥1,0 м; при наружном
   ≤0,3 м внутренний ≥2,0 м. Перепутанный порядок или несогласованная пара
   слоёв = конденсат остаётся запертым внутри утеплителя — тот же
   механизм скрытого дефекта, что и в сценарии несовместимых красок выше,
   только страшнее, потому что скрыт под кровлей, а не под слоем краски.
4. **Диффузионно-открытая Unterspannbahn** с наружной стороны утеплителя —
   должна быть заметно более паропроницаема, чем внутренний слой (см. п.3),
   иначе влага, прошедшая изнутри, не может выйти наружу.
5. **Контробрешётка (Konterlattung)** — формирует вентиляционный зазор
   (Hinterlüftung) между Unterspannbahn и кровельным покрытием. Пропуск =
   отсутствие проветривания, накопление влаги под черепицей, ускоренное
   гниение обрешётки уже в новой конструкции.
6. **Обрешётка (Dachlattung)** — шаг (Lattweite) рассчитывается под
   конкретный формат и величину нахлёста используемой черепицы/плитки по
   данным производителя, не берётся "как обычно" — неверный шаг = черепица
   не садится по нахлёсту корректно, тот же риск протечки, что и
   недостаточный уклон.
7. **Покрытие (Eindeckung)** — укладка черепицы/бетонной плитки с боковым и
   верхним нахлёстом по факт. уклону (не по табличному "среднему").
8. **Примыкания (Anschlüsse)** — конёк (First), ендова (Kehle), фронтон
   (Ortgang), примыкание к стене/дымоходу (Wandanschluss) — каждое по
   отдельным разделам "Regeln für Dachdeckungen" ZVDH, каждое —
   самостоятельная типовая точка протечки при неверном исполнении,
   отдельная позиция в базе типовых работ, не часть "просто покрытия".

**Кровля плоская (Flachdach) — отдельная ветка, другая ATV-логика:**
ATV DIN 18338 регулирует именно скатную/дождь-отводящую кровлю
(Dachdeckung); для герметизирующей кровли (Dachabdichtung, включая
большинство плоских крыш, балконов, лоджий) технический стандарт —
отдельная норма **DIN 18531** ("Abdichtung von Dächern, Balkonen, Loggien
und Laubengängen", 5 частей: требования, планирование/исполнение,
материалы, виды гидроизоляции/детали, обслуживание), а отраслевой ориентир
по исполнению — **Flachdachrichtlinie** (ZVDH). Это ровно та же логика
разделения "ATV = договорной/юридический слой, DIN-стандарт исполнения =
технический слой", что уже видели у плитки (DIN 18352 ↔ DIN 18157). Ключевое
правило: **минимальный уклон 2%** по Flachdachrichtlinie (обеспечивает сток,
но не исключает кратковременного застоя воды), а для полного исключения
застоя воды на кровле рекомендуется уклон **от 5%**. Каждая плоская кровля
требует основного водоотвода **и** аварийного (Notentwässerung) на случай
ливня сверх расчёта основного — пропуск аварийного водостока = риск
переполнения и протечки при экстремальном осадке, не гипотетический сценарий
для немецкого климата с участившимися ливнями последних лет.

**Nebenleistungen по DIN 18338 (уже включено в цену, без отдельной
оплаты)**: монтаж/демонтаж/содержание лесов с рабочей площадкой не выше
**2 м** от земли/перекрытия — заметно строже порога 3,5 м у малярных работ
(DIN 18363, см. выше), логично: кровельные работы по определению идут на
высоте, порог именно для того, чтобы отличить "приставная стремянка/
минимальный трап" от полноценных лесов как отдельной позиции. **Для
продукта**: при вводе "переукладка кровли"/"новая кровля" приложение должно
спросить высоту конька от земли и предложить отдельную позицию за леса
почти всегда (в отличие от малярки, где леса часто остаются included).
**Это правило (2 м) взято из вторичных источников (страница dachdecker.com
заблокирована egress-прокси при прямой проверке) — требует сверки по
первоисточнику ATV DIN 18338 на следующей ревизии**, помечено как
предварительно подтверждённое, не как 100%-но проверенный факт.

**Стропильная система (Dachstuhl, новый монтаж или полная замена) —
проработано 2026-08-16**, тот же принцип, что и графы выше — что ломается
при нарушении порядка, не просто список позиций:
1. **Обмер и расчёт нагрузки/пролёта до заказа материала** — сечение и
   класс прочности бруса подбираются под конкретный пролёт/снеговую и
   ветровую нагрузку по DIN EN 1995 (Eurocode 5), не берутся "как в
   прошлый раз" — ошибка здесь означает несущую конструкцию,
   не соответствующую расчёту, которую относительно дёшево исправить до
   монтажа и очень дорого — после.
2. **Проверка/подготовка опорной конструкции** (Mauerwerkskrone,
   Ringanker, существующая стена) — стропильная система опирается на
   несущую конструкцию, которая должна быть готова и на нужной отметке
   ДО подвоза и подъёма бруса, иначе простой бригады на объекте
   оплачивается отдельно, если вина не на стороне зимера.
3. **Монтаж несущего каркаса** (Fußpfette/Mittelpfette/Firstpfette,
   стропильные ноги) — с контролем влажности материала при приёмке на
   объект (порог 18%, см. раздел про Zimmerer ниже) и геометрии по
   проекту.
4. **Для видимых конструкций** — контроль качества древесины
   (Kernschnitt, острая кромка заболони) на этом же шаге, пока ещё можно
   заменить отдельный брус — после закрытия обшивкой/утеплением исправить
   косметический дефект видимой конструкции уже нельзя без демонтажа.
5. **Временное укрытие от осадков**, если монтаж многодневный и кровельное
   покрытие/Unterspannbahn не закрывает конструкцию в тот же день — иначе
   свежесмонтированный, ещё не защищённый каркас намокает и превышает
   допустимую влажность ДО того, как вообще был принят объект (это
   отдельная позиция, не бесплатная опция — см. Nebenleistungen в разделе
   про Zimmerer ниже).
6. **Передача каркаса кровельщику (или тому же зимеру, если бригада
   универсальная) для дальнейшего закрытия** — переход к уже расписанной
   последовательности раздела "Кровля" выше (Unterspannbahn →
   Konterlattung → Dachlattung → Eindeckung). **Для продукта**: если
   бригада выполняет оба этапа сама, приложение должно вести это как одну
   непрерывную цепочку позиций одного объекта, а не как два несвязанных
   документа — важно для последующей документации, кто и когда закрыл
   каждый слой (см. сценарий спора №8 про гнилые стропила — тот же
   принцип "фото до закрытия следующим слоем" применим и здесь, только
   на этапе нового строительства, а не реновации).

## Специализации — стандарты по каждой

### Гипсокартон/шпаклёвка (Trockenbau)
- VOB/C: **DIN 18340** (Trockenbau), **DIN 18299** (общие правила),
  **DIN 18352** (Fliesen-/Plattenarbeiten)
- Классы качества шпаклёвки **Q1-Q4** (DIN 18340/ATV): Q1 — только швы,
  Q2 — стандарт, Q3 — Sonderverspachtelung (требует явной спецификации),
  Q4 — полное шлифованное покрытие
- Пример подсказки: "шпаклёвка" → шлифовка, грунтовка, выбор Q1-Q4,
  кол-во слоёв

### Электрика (Elektroinstallation) — проработано 2026-08-20

- **Почему эта специализация выбрана для углубления именно сейчас, а не
  очередной ATV по каталогу**: электрика, сантехника, отопление и
  вентиляция — те четыре специализации, которые владелец назвал явно
  ("electrical/plumbing/HVAC/heating во всех их вариациях"), но
  парадоксальным образом именно они оставались в этом документе самыми
  поверхностными разделами (по 10-15 строк списком, без графа
  последовательности, без разбора Nebenleistungen, без единого сценария
  спора) — в то время как специализации, всплывшие по ходу (плитка,
  кровля, зимер, металл), получили полную проработку. То есть выбор
  сегодня — не расширение каталога вширь, а закрытие разрыва между
  явно заявленным приоритетом владельца и фактическим состоянием
  документа. Дополнительный аргумент: у электрики самая высокая цена
  ошибки (жизнь и здоровье, а не косметика или протечка) и —
  как выяснилось при разборе ниже — **единственная из всех уже
  расписанных специализаций, где протокол о выполненной работе является
  не "хорошей практикой", а нормативно требуемым документом**, что
  напрямую меняет позиционирование продукта, а не просто добавляет
  подсказок в базу.

**Договорной слой — ATV DIN 18382, действующая редакция 2023-09:**

- VOB/C: **DIN 18382** "Elektro-, Sicherheits- und informationstechnische
  Anlagen". **Действующая редакция — 2023-09, она заменила 2019-09**
  (в прошлых ревизиях этого документа редакция не указывалась вовсе —
  исправлено). Область действия — средне- и низковольтные установки до
  **20 кВ**, осветительные установки, системы связи, тревожные и
  охранные системы, медиатехника, передающие сети внутри зданий и
  связанные с ними несамостоятельные наружные установки. Структура —
  стандартная для ATV (Geltungsbereich, Stoffe/Bauteile, Ausführung,
  Nebenleistungen/Besondere Leistungen, Abrechnung), та же логика
  "ATV = договорной слой, DIN VDE = технический слой исполнения", что уже
  применялась выше к паре DIN 18352 ↔ DIN 18157 (плитка) и DIN 18338 ↔
  ZVDH-Regelwerk (кровля).
- **Ключевое изменение редакции 2023-09 против 2019-09 — прямо в тему
  продукта**: в раздел про приёмку и документацию (Abnahme und
  Dokumentation) **заново включены обзорные схемы (Übersichtsschaltpläne)
  и протоколы измерений (Messprotokolle)**, отдельно выделенные для
  аудиовизуальной и медиатехники. То есть протокол измерений — это уже не
  только требование технической нормы VDE (см. ниже), но и элемент
  **договорной** документации по действующей ATV. Для продукта это
  означает: PDF, который генерирует приложение по электромонтажным
  работам, должен уметь быть не только "смета + фото + подпись", но и
  нести/прикладывать протокол измерений — иначе документ не закрывает
  договорную обязанность, которую ATV прямо называет.
- **Nebenleistungen vs. Besondere Leistungen**: общий принцип тот же, что
  уже разобран для маляра (порог лесов 3,50 м) и кровельщика (порог 2 м) —
  Nebenleistung входит в цену по умолчанию, Besondere Leistung
  оплачивается отдельно и должна быть явной позицией. **Практически
  важный для электрика пограничный случай — штробление и пробивка
  проёмов (Schlitze und Durchbrüche)**: по найденному материалу это
  трактуется как Besondere Leistung, то есть отдельно оплачиваемая
  позиция, а не подразумеваемая часть работы электрика. **Оговорка:
  это утверждение сегодня подтверждено только через изложение
  тендерной практики (VOB/A §7 — требование отдельной позиции), прямой
  текст раздела 4 ATV DIN 18382 через egress-прокси не открылся —
  отмечаю как требующее сверки по первоисточнику, не как
  100%-но проверенный факт.** Для продукта важна не столько сама
  классификация, сколько то, что это ровно та позиция, о которой
  спорят чаще всего ("я думал, штробление входит в цену проводки") —
  значит, приложение должно заставлять решать её явно, независимо от
  того, как её квалифицирует ATV.

**Технический слой — DIN VDE 0100 и обязательная Erstprüfung по
DIN VDE 0100-600:**

Нормативная база исполнения — серия **DIN VDE 0100** (8 групп, 60+
частей). Ключевые части для типового жилого объекта:
- **DIN VDE 0100-410** — защита УЗО (RCD) 30 мА обязательна на
  розеточных группах до 32 А, доступных неспециалисту; с октября 2018
  дополнительно — на осветительных цепях в жилых помещениях. Требование
  RCD на розетках до 32 А действует **с 01.06.2007** — конкретная дата
  важна, потому что она определяет, что считалось нормой на момент
  монтажа существующей установки (см. сценарий спора №12 ниже).
- **DIN VDE 0100-600** — Erstprüfung (первичная проверка) установки
  после монтажа или существенного изменения. Для повторных проверок
  действует отдельная норма **DIN VDE 0105-100** — это разные нормы,
  их нельзя путать в документе.

**Почему Erstprüfung — центральный факт для этого продукта, а не
техническая деталь для электрика**: протокол проверки — это
**единственное доказательство того, что проверка вообще проводилась и
что установка соответствовала требованиям на момент проверки**. Без
протокола проверка для надзорных органов и суда считается просто не
состоявшейся — независимо от того, действительно ли мастер всё
измерил. Это ровно тот же принцип, который уже выведен в этом документе
для Prüf- und Hinweispflicht (сценарии 7-8: бремя доказательства, что
предупреждение было сделано, лежит на мастере) и для фото скрытых слоёв
(сценарий 6) — но здесь он не выведен по аналогии из общего принципа
добросовестности, а прямо закреплён в технической норме. **Следствие
для позиционирования продукта**: для электрика приложение — это не
"удобнее, чем блокнот", а инструмент выпуска нормативно требуемого
документа. Это самый сильный аргумент продажи из всех, найденных до сих
пор в этом документе, и он специфичен именно для электрики — у маляра
или плиточника аналогичной обязательной формы протокола нет.

**Последовательность Erstprüfung — Besichtigen → Erproben → Messen**
(порядок не произволен: осмотр до подачи напряжения, измерения на
обесточенной установке до функциональных испытаний под напряжением —
нарушение порядка опасно для жизни проверяющего, а не только методически
неверно). Обязательный состав измерений и ориентировочные предельные
значения:
- **Непрерывность защитных проводников и уравнивания потенциалов**
  (Durchgängigkeit) — базовая проверка, что PE действительно соединён.
- **Сопротивление изоляции** — измерение при **500 В постоянного тока**
  для установок 230/400 В, между активными проводниками (L, N) и PE на
  обесточенной установке, предельное значение **≥1 МОм**.
- **Полное сопротивление петли короткого замыкания (Schleifenimpedanz)**
  — определяет, отключится ли защитный аппарат за нормированное время;
  измеряется по петле "фазный проводник → защитный проводник".
- **Испытание УЗО (RCD)** — фактический ток и время срабатывания.
  Ориентир по практике: типичное время срабатывания 20-40 мс (зависит от
  производителя), нормативный максимум — до 300 мс в зависимости от
  формы сети и напряжения. **Эти конкретные числа взяты из
  вторичных источников/сниппетов, полный текст нормы не открывался —
  использовать как ориентир для формы протокола, не как значения,
  которые продукт может утверждать как нормативные.**
- **Сопротивление заземления** — если требуется выбранной мерой защиты.

**Проект новой редакции E DIN VDE 0100-600:2025-12 — прямой попутный
ветер для продукта, но с честной оговоркой о статусе:**
- Проект опубликован в декабре 2025, **срок подачи возражений
  (Einspruchsfrist) истёк 14.01.2026**. **До публикации новой редакции
  действующей признанной нормой техники остаётся DIN VDE 0100-600:2017-06**
  — то есть на сегодня (август 2026) это ещё проект, а не действующая
  норма, и продукт не должен ссылаться на него как на обязательное
  требование.
- **Здесь источники расходятся по масштабу изменений, и это расхождение
  я воспроизвожу честно, а не усредняю**: официальное описание изменений
  (каталог норм) перечисляет узкий список — (а) актуализация нормативных
  ссылок, (б) добавлено приложение (Anhang I) о повторных проверках
  электроустановок в жилых зданиях. Отраслевая же пресса описывает
  проект заметно шире — как существенное ужесточение документирования:
  протоколы должны содержать **полные единичные измеренные значения
  вместо обобщающей отметки "пройдено"**, значения срабатывания RCD,
  уравнивание потенциалов и **данные о самом измерительном приборе и его
  статусе поверки/калибровки** должны документироваться прослеживаемо;
  растёт значение цифровых, защищённых от ретроактивного изменения
  (revisionssicher) протоколов; фотодокументация обсуждается, но
  **пока не обязательна**. **Оценка**: формулировка отраслевой прессы
  выглядит как интерпретация направления развития нормы, а не как
  дословный пересказ списка изменений — поэтому я НЕ утверждаю
  "с 2026 года документация станет строже" как факт, а фиксирую как
  подтверждённое направление с неподтверждённой точной силой.
  **Открытый вопрос: свести реальный текст проекта (что именно в нём
  про содержание протокола) — требует платного доступа к VDE-Verlag/
  DIN Media, egress-прокси не пропускает.**
- **Почему это всё равно важно для продукта даже в статусе проекта**:
  направление однозначно — от бумажной галочки "geprüft" к цифровому
  протоколу с прослеживаемыми единичными значениями и привязкой к
  прибору. Приложение, которое уже сегодня фиксирует структурированные
  значения с таймштампом и фото на объекте, движется в ту же сторону, а
  не против неё. Это аргумент для дорожной карты (какие поля закладывать
  в протокол сейчас, чтобы не переделывать потом), а не для маркетинга
  ("соответствуем новой норме" — было бы неточным утверждением, пока
  норма не опубликована).

**Ванные комнаты — DIN VDE 0100-701:2025-06, новая редакция с
переходным периодом (важнейшая практическая новость раздела):**
- **Действует с 01.06.2025**, заменила редакцию 2008-10. **Переходный
  период — до 06.12.2027**: для установок, уже находящихся в
  планировании или в процессе монтажа, до этой даты допускается старая
  редакция; установки, завершённые после 06.12.2027, должны полностью
  соответствовать новой.
- **Главное изменение структуры зон**: прежний **Bereich 3 упразднён** —
  теперь только зоны **0, 1, 2** плюс "вне зон" с общими требованиями.
  Bereich 2 ограничен по горизонтали высотой до 225 см и по вертикали
  расстоянием **60 см** вокруг зоны 1.
- **Розетки и выключатели не допускаются в зонах 0, 1 и 2** — только
  вне этих зон.
- **RCD ≤30 мА обязателен для ВСЕХ цепей в зоне ванной, без исключений**
  (в прежней редакции исключения существовали — в частности обсуждается
  распространение обязанности и на водонагреватели).
- **Упрощение**: если защитное уравнивание потенциалов обеспечено через
  главный заземляющий проводник, **дополнительное местное уравнивание
  потенциалов (zusätzlicher Schutzpotentialausgleich) может не
  выполняться**.
- **Вывод для продукта, которого нет ни у одного конкурента и который
  прямо следует из переходного периода**: с 01.06.2025 по 06.12.2027 в
  Германии одновременно легальны две разные редакции нормы для одной и
  той же работы. Значит, для ванной комнаты **вопрос "по какой редакции
  выполнено" — не педантизм, а фактор того, является ли работа
  бездефектной**. Приложение должно фиксировать в документе явно:
  дату начала работ/планирования (чтобы обосновать применимость старой
  редакции) и применённую редакцию нормы. Это тот же по своей природе
  механизм, что уже разобран в сценарии 9 (способ крепления террасы
  определяет срок гарантии 2 или 5 лет) — один зафиксированный факт с
  прямым юридическим последствием, который постфактум восстановить
  невозможно, а в момент работы записать почти бесплатно. **Отдельно
  отмечаю как ценное для владельца**: после 06.12.2027 это правило
  перестанет быть развилкой и станет просто нормой — то есть это
  временнáя, а не вечная функция, и закладывать её надо с датой
  истечения, а не как постоянную логику.

**Объём работ в жилом помещении — DIN 18015-2:2021-10 и RAL-RG 678
(основа автоподсчёта и одновременно источник спора об ожиданиях):**
- **DIN 18015-2** (действующая редакция **2021-10**) — вид и объём
  **минимального** оснащения электрикой в жилых зданиях. Минимальное
  количество цепей для розеток общего назначения и освещения
  определяется площадью квартиры по таблице: **до 50 м² — 3 цепи,
  свыше 125 м² — 7 цепей** (промежуточные значения — по таблице нормы,
  полный текст таблицы сегодня не открывался, отмечаю как неполные
  данные).
- **RAL-RG 678** — отдельный отраслевой ориентир, описывающий оснащение
  **сверх** минимума DIN 18015-2, через три **Ausstattungswerte**
  (ступени оснащения): ступень 1 — минимум, ступень 2 — стандарт,
  ступень 3 — повышенный комфорт. Количество розеток и доля
  осветительных/коммуникационных точек зависят от размера помещения и
  выбранной ступени.
- **Почему это не справочная таблица, а прямой источник спора об
  ожиданиях (и основание сценария №13 ниже)**: разница между ступенью 1
  и ступенью 3 — это кратная разница в количестве точек, то есть кратная
  разница в цене за ту же формулировку заказа "сделать электрику в
  комнате". Заказчик, который видел современную квартиру у знакомых
  (де-факто ступень 3), и мастер, посчитавший по минимуму DIN 18015-2
  (ступень 1), говорят одними словами о разных объёмах — и расходятся
  не на приёмке, а в момент, когда розеток на стене оказывается вдвое
  меньше ожидаемого. **Для продукта**: при вводе "электрика комната"
  приложение должно не подставлять один "нормальный" объём по
  умолчанию, а явно предъявлять развилку ступени оснащения с
  количеством точек и ценой — и фиксировать выбор в подписываемом
  документе. Это тот же принцип "сделать неявное ожидание явным до
  начала работы", что уже применён для класса шпаклёвки Q1-Q4
  (Trockenbau) и количества слоёв краски (DIN 18363) — но здесь
  ценовая вилка заметно шире.

**Bestandsschutz в электрике — важная поправка к тому, как этот термин
использован в сценарии 11 (перила):**

При разборе Metallbau (ревизия 2026-08-19) Bestandsschutz работал как
понятие строительного надзорного права: старое ограждение легально
стоит, пока его не заменили целиком. **В электротехнике ситуация
принципиально иная, и это не нюанс формулировки, а другое устройство
правила**: понятие "Bestandsschutz" не закреплено ни в DIN VDE 0100-200,
ни в других нормах DIN VDE, и отсутствует в Betriebssicherheitsverordnung
и Arbeitsstättenverordnung — оно происходит из строительного права и на
электроустановки прямо не переносится. Практическое правило вместо него
складывается так:
- **Действующие нормы для вновь возводимых установок не содержат
  требования принудительно переводить старые установки с TN-C
  (klassische Nullung) на TN-S.** То есть само по себе наличие старой
  установки не создаёт обязанности её модернизировать — заказчика нельзя
  заставить.
- **Но цепи с классической нулёвкой не соответствуют состоянию техники**
  (Stand der Technik), и **с мая 1973 (по другим источникам — с апреля
  1974) классическую нулёвку нельзя применять для новых установок и для
  расширений установок.**
- **Замена дефектного элемента** на новый **точно той же функции** не
  требует приведения к состоянию техники. (Это ровно тот случай, который
  клиент формулирует как "просто поменяй розетку".)
- **А вот расширение или изменение — уже другой режим**: по **DIN VDE
  0100-100, раздел 11.2** норма распространяется на расширение/изменение
  установки **и на те части существующей установки, которые этим
  расширением или изменением затронуты (beeinflusst)**. Слово
  "затронуты" — и есть точка, где рождается неожиданный для клиента
  объём работ (см. сценарий спора №12 ниже).
- **Пример механики, который делает это осязаемым**: цепи для розеток
  снаружи должны быть защищены RCD ≤30 мА — и защищён должен быть
  **весь участок цепи вплоть до имеющейся розетки**, а не только новый
  отрезок. В цепи, выполненной классической нулёвкой (двухпроводной),
  это означает необходимость замены всей линии, а не добавления одного
  автомата в щиток.

**Технологическая последовательность электромонтажа — что ломается при
нарушении порядка** (тот же формат, что для штукатурки/плитки/кровли
выше, потому что ценность именно в этом, а не в списке позиций):
1. **Обследование существующей установки ДО расчёта цены** — тип системы
   (TN-C/TN-S/TN-C-S), наличие PE, наличие и тип RCD, состояние щитка,
   год монтажа. Это шаг, который в электрике заменяет "Untergrundprüfung"
   маляра и осмотр стропил кровельщика: без него мастер не знает, во что
   превратится "добавить одну розетку" (сценарий 12). **Пропуск = цена
   названа до того, как выяснен реальный объём** — то есть спор
   гарантирован не технологией, а арифметикой.
2. **Планирование объёма и ступени оснащения с заказчиком**
   (DIN 18015-2 минимум vs. RAL-RG 678 ступень 2/3) — до штробления,
   потому что после закрытия штроб добавление точки означает повторное
   вскрытие стены и повторную отделку (то есть работу других
   специализаций — маляра/штукатура, уже расписанных выше).
3. **Штробление/пробивка (вероятная Besondere Leistung — см. выше) и
   прокладка кабеля** — с соблюдением допустимых зон прокладки
   (Installationszonen), чтобы последующие работы других бригад
   (навеска шкафов, сверление под плитку) не попадали в кабель. Нарушение
   = скрытый дефект, который проявится чужими руками через месяцы —
   тот же класс "дефект вскроется позже", что и в сценарии 6.
4. **Фотофиксация трасс ДО закрытия штроб штукатуркой/гипсокартоном** —
   абсолютный аналог "фото стропил до закрытия Unterspannbahn"
   (сценарий 8) и фото гидроизоляции до укладки плитки (сценарий 6). Для
   электрики у этого фото есть дополнительная, чисто практическая
   ценность помимо спора: это единственный способ через годы узнать, где
   проходит кабель, — то есть ценность документа для самого заказчика,
   которую легко объяснить при продаже.
5. **Монтаж щитка, механизмов, подключение** — с маркировкой цепей.
6. **Erstprüfung по DIN VDE 0100-600** (Besichtigen → Erproben → Messen)
   и **оформление протокола измерений** — не после сдачи "когда будет
   время", а до передачи установки в эксплуатацию: протокол фиксирует
   состояние **на момент проверки**, задним числом он теряет смысл.
7. **Передача заказчику**: протокол измерений + обзорная схема
   (Übersichtsschaltplan) — по ATV DIN 18382:2023-09 это часть
   документации приёмки, а не любезность.

**Примеры подсказок (с учётом всего разобранного выше):**
- "розетка" → сначала вопрос о существующей системе (есть ли PE / это
  расширение существующей цепи или новая), тип цепи, УЗО 30 мА
  (VDE 0100-410), кабель NYM-J 3×1,5 мм², автомат 16 A тип B, IP-класс
  по месту; **при признаках старой установки — предупреждение о правиле
  "затронутых частей" (DIN VDE 0100-100, 11.2) и о том, что цена за
  "одну розетку" может не покрыть требуемый объём**.
- "розетка/светильник ванная" → зоны 0/1/2 по **DIN VDE 0100-701:2025-06**
  (Bereich 3 больше нет), розетки только вне зон 0-2, RCD ≤30 мА на все
  цепи без исключений, вопрос о дате начала планирования/работ для
  фиксации применённой редакции (переходный период до 06.12.2027).
- "электрика комната/квартира" → площадь → минимальное число цепей по
  **DIN 18015-2:2021-10** → явная развилка ступени оснащения
  (RAL-RG 678: минимум/стандарт/комфорт) с числом точек и ценой, а не
  один "обычный" объём по умолчанию.
- "кабель" → тип (NYM-J внутри / NYY-J под землёй), радиус изгиба,
  соблюдение Installationszonen, документирование Zugentlastung,
  **обязательное фото трассы до закрытия штробы**.
- "распределительный щиток" → селективность УЗО/автоматов по цепям,
  маркировка цепей, обзорная схема как часть документации приёмки
  (ATV DIN 18382:2023-09).
- **Сквозная подсказка для любой электромонтажной позиции**: по
  завершении — Erstprüfung по DIN VDE 0100-600 и протокол измерений с
  единичными значениями (изоляция ≥1 МОм при 500 В DC, петля КЗ, время
  и ток срабатывания RCD, непрерывность PE), с указанием измерительного
  прибора — форму протокола закладывать сразу с полями под единичные
  значения и данные прибора, с прицелом на направление проекта
  E DIN VDE 0100-600:2025-12.

### Сантехника (Sanitärinstallation) — проработано 2026-08-21

- **Почему эта специализация выбрана сегодня, а не Heizung/Klima**: та же
  логика, что уже применена вчера к электрике — сантехника прямо названа
  владельцем ("electrical/plumbing/HVAC/heating"), но до сегодняшнего дня
  оставалась разделом-заготовкой (5 строк списком, без графа
  последовательности, без Nebenleistungen/Besondere Leistungen, без
  единого сценария спора), пока три названные владельцем специализации
  формально равноправны по приоритету. Сантехника выбрана из оставшихся
  трёх (Sanitär/Heizung/Klima) первой, потому что именно здесь сегодня
  нашлись два самых сильных материала для проработки: (а) реальное
  судебное дело с прямым, посчитанным ущербом (≈€126 000) от скрытого
  дефекта монтажа сантехники — сильнее любого найденного до сих пор кейса
  по деньгам (см. сценарий 14 ниже), и (б) требование (Rückstausicherung),
  которое, в отличие от большинства других разделов документа, не просто
  вопрос качества, а прямая связка с тем, оплатит ли страховка ущерб
  заказчику (см. сценарий 15). Оба аргумента специфичны для воды —
  ошибка в отоплении/вентиляции реже создаёт ущерб такого масштаба и
  скорости, что отчасти объясняет и то, почему в стройотрасли Sanitär
  традиционно котируется как более рискованная специализация, чем Heizung
  для той же малой бригады.

**Договорной слой — ATV DIN 18381, действующая редакция 2019-09:**

- VOB/C: **DIN 18381**, полное название "Gas-, Wasser- und
  Entwässerungsanlagen innerhalb von Gebäuden" (в части источников
  встречается под более разговорным названием "Gas-, Wasser- und
  Abwasser-Installationsarbeiten innerhalb von Gebäuden" — то же самое
  содержание). Структура норматива — та же, что и у уже расписанных ATV
  выше (Elektro/Metallbau/Dachdecker/Maler): Geltungsbereich,
  Stoffe/Bauteile, Ausführung, Nebenleistungen/Besondere Leistungen,
  Abrechnung.
- **Nebenleistungen** дополнительно к общим по DIN 18299: проверка
  документов заказчика по разделу 3.1.3 (например существующей схемы
  разводки/плана этажа) — входит в цену по умолчанию.
- **Besondere Leistungen** дополнительно к общим по DIN 18299:
  проектировочные услуги (Entwurfs-, Ausführungs- und
  Genehmigungsplanung) и **прямо названное в самой ATV планирование
  штроб и проходок (Schlitze und Durchbrüche)**. **Это заметно увереннее
  подтверждено, чем аналогичный вывод для электрика вчера** — там
  квалификация штробления как Besondere Leistung опиралась только на
  изложение тендерной практики VOB/A (косвенный источник), здесь она
  найдена как прямая формулировка самого текста ATV DIN 18381 (через
  независимый вторичный пересказ структуры нормы, не как текст раздела
  4 напрямую — оговорка по методу та же, что и везде в этом документе:
  сам текст ATV платный, dinmedia.de не открылся напрямую). **Для
  продукта**: тот же вывод, что и у электрика — при штроблении под трубу
  приложение должно предлагать штробление отдельной позицией по
  умолчанию, а не включать её молча в цену монтажа сантехники.

**Технический слой — DIN 1988-200 + DIN EN 806-2 (планирование,
гигиена), действующая редакция 2012-05:**

- DIN 1988-200 действует совместно с **DIN EN 806-2** для планирования
  Trinkwasser-Installation (geschlossenes System). Текущая найденная
  редакция — **2012-05**; более новой редакции части 200 сегодня не
  найдено (для сравнения, соседняя **DIN 1988-500:2021-05** — это другая
  часть серии, не путать с частью 200 при следующей проверке).
- **Таблица 8** задаёт минимальную толщину теплоизоляции труб в
  зависимости от температуры и влажности окружающего воздуха — для
  холодной воды цель не энергосбережение, а предотвращение (а)
  конденсата на трубе и (б) нагрева воды выше **25°C** (верхний
  гигиенический предел для холодной воды).
- **"Правило трёх литров"**: если объём воды в участке трубы между
  выходом водонагревателя и точкой водоразбора превышает **3 литра**,
  обязательна циркуляционная линия или самонагревающийся
  температурный пояс (иначе вода застаивается и остывает ниже
  безопасной температуры — риск легионеллы). На выходе водонагревателя
  с циркуляцией по гигиеническим причинам должна поддерживаться
  температура **не менее 60°C**.
- **Находка сегодня, которая напрямую усиливает продуктовый аргумент, а
  не просто техническая деталь**: те же **"3 литра"** — это не только
  инженерное правило проектирования DIN 1988-200, а одновременно точный
  юридический порог в **Trinkwasserverordnung (TrinkwV)**, который
  определяет **"Großanlage"** (крупная установка подогрева питьевой
  воды): накопительный или проточный водонагреватель объёмом >400 л
  **или** содержание хотя бы одного участка трубы между выходом
  нагревателя и точкой разбора >3 л. Для сдаваемых в аренду объектов
  Großanlage подлежит обязательной **проверке на легионеллу раз в 3
  года**, с уведомлением ведомства при превышении технического
  контрольного значения 100 КОЕ/100 мл. **Вывод для продукта**: мастер,
  который на объекте прокладывает трубу горячей воды длиннее, чем на
  3 литра, без циркуляции — не просто рискует гигиеной, а создаёт для
  собственника арендуемого объекта юридически регулируемую "Großanlage"
  с новой периодической обязанностью проверки, о которой собственник
  скорее всего не знает и не просил. Голосовой ввод "труба горячей воды"
  должен не только предложить изоляцию по таблице 8, но и посчитать
  примерный объём участка и предупредить о переходе в статус Großanlage,
  если объект сдаётся в аренду — это прямая параллель тому, как
  Erstprüfung у электрика превращает документ приложения из "удобной
  бумажки" в инструмент, закрывающий реальную нормативную обязанность
  заказчика.
- **DIN EN 1717** — защита питьевой воды от загрязнения через обратный
  поток (Rückfließen): делит жидкости на 5 категорий риска и требует
  соответствующее устройство защиты (Systemtrenner, свободный слив и
  т.д.) по требованию **TrinkwV §17**. **Свежая находка, параллельная
  вчерашнему E DIN VDE 0100-600:2025-12 у электрика**: действующая
  редакция сегодня — **DIN EN 1717:2026-02**, которая заменила версию
  2011-08 буквально в феврале 2026 года, то есть за полгода до этой
  ревизии. **Открытый вопрос**: что конкретно изменилось в новой
  редакции по содержанию (не только факт замены) — не проверено сегодня,
  требует сверки на следующей ревизии, не выдаю факт замены за знание
  содержания изменений.

**Rückstausicherung — DIN EN 12056 / DIN 1986-100, обязательное
требование, не рекомендация:**

- Точки слива (раковина, душ, WC) **ниже уровня подпора (Rückstauebene —
  верх ближайшего смотрового колодца канализации + 15 см на ровном
  рельефе)** обязаны иметь **активную защиту от подпора**: по умолчанию
  это автоматическая канализационная насосная станция (**Hebeanlage**) с
  обратной петлёй. Пассивная защита (**Rückstauklappe**, обратный
  клапан) допустима только в узких исключительных случаях по критериям
  **DIN EN 13564** — то есть это не взаимозаменяемая по цене альтернатива
  "подешевле", а редкое исключение, а не правило по умолчанию.
- **Ограничение для Fäkalienzerkleinerer** (компактная измельчающая
  установка, часто предлагается как дешёвая альтернатива Hebeanlage):
  допустима только если в этом же здании есть **ещё один WC выше уровня
  подпора** — то есть не годится как единственный туалет в переоборудованной
  отдельной подвальной квартире (Souterrainwohnung).
- **Денежный аргумент продукта — прямая связка со страховкой**: минимум
  половина немецких страховщиков Wohngebäudeversicherung платит по ущербу
  от подпора **только при наличии исправной и обслуживаемой
  Rückstausicherung**; отсутствие или неисправность устройства — законное
  основание для отказа или урезания выплаты. Бремя доказательства, что
  устройство было и работало, лежит на страхователе (заказчике) — та же
  логика "без документа защита не сработает", что уже неоднократно
  выведена в этом документе для Erstprüfung, фото скрытых слоёв и
  Bedenkenanmeldung.
- Обслуживание — по интервалам производителя; отсутствие обслуживания
  расценивается страховщиком так же, как отсутствие устройства.

**Dichtheits-/Druckprüfung — обязательна до закрытия трубы стеной/полом,
тот же документационный принцип, что и Erstprüfung в электрике:**

- После прокладки новых трубопроводов питьевой воды обязательна
  **Dichtheits- und Belastungsprüfung** по **DIN EN 806-4** / отраслевому
  **ZVSHK-Merkblatt** / **VDI/DVGW 6023**, с обязательным протоколированием
  результата **ДО** того, как труба будет закрыта штукатуркой/стяжкой/полом.
  Испытательная среда — вода, чистый безмасляный сжатый воздух или
  инертный газ (азот).
- **Прямая связь с сегодняшним судебным делом (сценарий 14 ниже)**:
  найденный сегодня прецедент об ответственности сантехника за плесень,
  проявившуюся через годы, упирается ровно в этот момент — неисправное
  уплотнение на стыке трубы, закрытое без достаточного контроля/
  документации перед сдачей. Это на сегодня самый конкретный
  довод из всего документа в пользу того, что фото/протокол опрессовки
  должны быть обязательным полем, а не опциональной галочкой в
  приложении — та же логика, что уже применена к Erstprüfung
  электрика и к фото стропил до закрытия кровли (сценарий 8), только
  здесь она подкреплена реальной суммой ущерба (≈€126 000).
- **Оговорка по силе источника, важная, чтобы не переоценить параллель с
  электрикой**: у электрика обязанность протокола Erstprüfung закреплена
  прямо в тексте ATV DIN 18382:2023-09 (договорной, а не только
  технический слой). Для сантехники сегодня подтверждена обязательность
  протокола опрессовки только на уровне отраслевого технического правила
  (DIN EN 806-4 / ZVSHK-Merkblatt / VDI/DVGW 6023, признанные "anerkannte
  Regeln der Technik"), не как прямое требование текста самой ATV DIN
  18381 — юридическая сила сопоставима (отступление от anerkannte Regeln
  der Technik само по себе создаёт презумпцию вины при дефекте, что и
  показывает дело BGH VII ZR 257/08 ниже), но источник формально другого
  уровня, и это различие явно сохраняется в тексте, а не сглаживается.

**GEG vs. DIN 1988-200 — частая путаница, которую стоит явно развести
для продукта:**

- **Gebäudeenergiegesetz (GEG) §§69-70 + Anlage 8** регулирует толщину
  изоляции только для **тёплых** труб (отопление, горячая питьевая вода,
  циркуляция) — например для PWH (Trinkwasser warm) толщина изоляции
  должна быть не менее внутреннего диаметра трубы (при теплопроводности
  материала λ=0,035 Вт/(м·К)).
- **Холодная питьевая вода прямо НЕ регулируется GEG** — её требование к
  изоляции (защита от конденсата и нагрева выше 25°C) идёт из **DIN
  1988-200, таблица 8**, отдельного источника с другой логикой
  обоснования (не энергосбережение, а гигиена/защита от конденсата).
- **Для продукта**: если логика подсказок для позиции "изолировать трубу"
  не различает горячую и холодную воду, приложение рискует сослаться на
  неверную норму в документе для заказчика — это не косметическая
  тонкость, а конкретная ошибка в слое сопоставления "работа → стандарт",
  того же типа, что уже разбирался у ступеней/кровли (какой ATV/DIN
  применяется к какому случаю).

**DIN 4109 — Schallschutz, частый источник соседских споров в
Mehrfamilienhaus:**

- Предельный уровень шума от установок водоснабжения/водоотведения в
  защищаемых соседних помещениях (жилые/спальные) — **менее 30 дБ(A)**;
  повышенный (рекомендуемый, не обязательный) уровень — **25 дБ(A)**.
  Кратковременные единичные звуки при открытии/закрытии арматуры не
  учитываются.
- Канализационные трубы, проходящие через деревянные конструкции
  перекрытия, требуют **немедленной развязки по структурному звуку**
  (Körperschallentkopplung) — одной изоляции трубы недостаточно и это
  является нарушением DIN 4109/DIN EN 14366, отдельная техническая
  ошибка, а не вопрос вкуса.
- **Контекст, не отдельный сценарий спора (сегодня недостаточно источников
  для полноценного разбора, отмечаю как задачу на будущую ревизию)**:
  споры о звукоизоляции сантехники в Mehrfamilienhaus/WEG — известная,
  судящаяся область (например известно, что ремонт ванной одним
  собственником сам по себе не создаёт у соседей права требовать
  повышения звукоизоляции по актуальной норме для всего здания), но точный
  порог, когда именно возникает обязанность, сегодня не сведён по
  первоисточнику — не привожу конкретное решение, чтобы не выдумать.

**Технологическая последовательность (Rohinstallation в санузле) — что
ломается при нарушении порядка (тот же формат, что для
штукатурки/плитки/кровли/электрики выше):**

1. **Обмер и план разводки, включая расчёт положения Rückstauebene
   относительно каждой новой точки слива — ДО закупки материала и ДО
   цены.** Если новая точка (душ/WC) ниже уровня подпора, решение
   "нужна Hebeanlage" должно быть принято здесь, а не всплыть после
   монтажа — прямая параллель тому, как обследование существующей
   электроустановки должно предшествовать цене у электрика (см. выше).
2. **Прокладка водопроводных и канализационных труб (Rohinstallation)**
   — с соблюдением уклона канализационной трубы и допустимых зон
   прокладки. Ошибка здесь не видна не только визуально, но и
   функционально до начала активной эксплуатации — хуже, чем штроба
   электрика, потому что дефект (недостаточный уклон, плохое уплотнение)
   проявляется не сразу при первом использовании, а стохастически, через
   месяцы/годы (см. сценарий 14).
3. **Dichtheits-/Druckprüfung с протоколом — ДО закрытия стены/пола**
   (см. выше) — не после сдачи "когда будет время".
4. **Фотофиксация трасс и результата опрессовки ДО закрытия** — тот же
   принцип, что уже применён к электрике/кровле/стропилам/плитке выше.
5. **Передача эстафеты соседним специализациям** (штукатурка/стяжка/
   гидроизоляция/плитка) — уже расписанный выше граф "Плитка внутри
   помещения" описывает, что гидроизоляция идёт до плитки; это тот же
   физический слой конструкции, здесь фиксируется только точка передачи
   между Sanitär и Fliesen, чтобы в документе было видно, кто закрыл что
   и когда.
6. **Endmontage** — монтаж сантехприборов, подключение, функциональная
   проверка под реальным рабочим давлением.
7. **Передача заказчику**: протокол опрессовки как часть документации
   сдачи (см. оговорку по силе источника выше).

**Примеры подсказок (с учётом всего разобранного выше):**
- "раковина подключить" → DN15 подводка, запорные вентили, сифон по

  1717** (свежая редакция 2026-02).

  наличии второго WC выше уровня подпора в этом же здании.
- "труба горячей воды" → материал (медь/нержавейка/PE-Xal), толщина

- "новая водопроводная/канализационная линия" → после монтажа —

  структурному звуку (Körperschallentkopplung), не просто изоляция

### Отопление (Heizungsanlagen) — проработано 2026-08-22

- **Почему эта специализация выбрана для углубления именно сейчас**:
  электрика, сантехника, отопление и вентиляция — те четыре
  специализации, которые владелец назвал явно. Электрика (2026-08-20) и
  сантехника (2026-08-21) уже закрыты; отопление и вентиляция оставались
  последними двумя разделами-заготовками по 15-16 строк. Сегодняшний
  выбор — отопление, а не вентиляция, по трём причинам, а не просто
  "по порядку": (а) именно в отопительном праве прямо сейчас происходит
  крупнейшее за несколько лет изменение — **Gebäudemodernisierungsgesetz
  (GModG) вступил в силу 29.07.2026**, то есть на момент этой ревизии
  ему всего около трёх недель, и любая неточная информация здесь
  наносит клиентам владельца больше вреда, чем в любой другой уже
  разобранной специализации, потому что старое правило "65%
  возобновляемых" реально отменено, а не просто устарело в источниках;
  (б) у отопления, как выяснилось при разборе ниже, **тот же класс
  находки, что уже дважды всплывал в электрике и сантехнике** — ввод
  установки в эксплуатацию юридически заблокирован без определённого
  протокола, и это подтверждается сразу по двум независимым механизмам
  (гидравлическая балансировка и регистрация теплового насоса у
  сетевого оператора), а не по одному; (в) именно для отопления
  сегодня нашлась самая свежая и самая прямая судебная практика во всём
  документе — решение окружного суда **от июня 2026 года**, то есть из
  того же месяца, в котором работает это приложение, не архивный кейс
  многолетней давности.

**Договорной слой — ATV DIN 18380, действующая редакция 2019-09 (важное
отличие от Elektro/Sanitär):**

- VOB/C: **DIN 18380** "Heizanlagen und zentrale Wassererwärmungsanlagen".
  Область действия — устройство отопительных установок с центральной
  выработкой тепла и центральных установок горячего водоснабжения, а
  также относящихся к ним распределительных систем (отопление и
  охлаждение) на воде/водных смесях как теплоносителе.
- **В отличие от DIN 18381 (Sanitär) и DIN 18382 (Elektro), которые обе
  получили обновление до редакции 2023-09, для DIN 18380 такое
  обновление сегодня не подтверждено** — действующей прослеживаемой
  редакцией по нескольким независимым каталогам норм остаётся
  **2019-09**. Это стоит явно отметить как находку, а не молчаливо
  предположить единый цикл обновления для всех ATV: не каждая часть
  VOB/C переиздавалась в 2023 году одновременно, и продукт не должен
  утверждать для отопления те же формулировки про "актуальную редакцию
  2023", что уже корректны для электрики и сантехники.
- Полный текст раздела о Nebenleistungen/Besondere Leistungen для DIN
  18380 сегодня не поднимался (платный доступ через DIN Media/VDI, тот
  же ограничитель, что и для всех предыдущих ATV в этом документе) —
  открытый вопрос на следующую ревизию: точная граница для демонтажа
  старого котла (Entsorgung des Altkessels) и для временного отопления
  объекта на время долгого ремонта, которые по логике других
  специализаций (аналогично штроблению у электрика) вероятно относятся
  к Besondere Leistungen, но это не подтверждено по первоисточнику
  сегодня и не должно выдаваться продуктом за факт.

**Правовая рамка — GEG заменён на Gebäudemodernisierungsgesetz (GModG),
в силе с 29.07.2026, и что реально осталось от "Heizungsgesetz":**

- **Никакой общей обязанности менять исправный котёл нет и не появилось
  с реформой.** Bestandsschutz для существующих масляных/газовых
  котлов сохраняется, пока установка исправна и ремонтопригодна.
  Обязанность замены возникает только в **двух** случаях: (1)
  необратимая поломка (**Heizungshavarie**) и (2) **правило 30 лет**
  для котлов с постоянной температурой (**Konstanttemperaturkessel**) —
  не для всех типов котлов, а именно для этого технического класса.
  Продукт не должен подсказывать "замена обязательна" при любом
  визите к старому котлу — только при этих двух конкретных условиях,
  которые стоит закладывать как явную развилку вопросов, а не как
  фон.
- **Главное изменение GModG против прежнего GEG**: обязательная доля
  65% возобновляемой энергии при замене отопления **отменена**. Вместо
  неё — **ступенчатая квота климатически нейтрального топлива именно
  для новых газовых/масляных котлов**: минимум 10% с 2029, 15% с 2030,
  30% с 2035, 60% с 2040. Тепловые насосы, теплосети, гибридные и
  биомассовые установки остаются доступны без этой квоты и продолжают
  получать субсидии как наиболее эффективная технология — но с
  29.07.2026 клиент **не обязан** выбирать тепловой насос только из-за
  требования закона, выбор шире, чем был.
- **Привязка к муниципальному Wärmeplanung — и почему дата в этом
  правиле уже прошла на момент сегодняшней ревизии**: жёсткие
  требования к новому отоплению вступают в силу с даты готовности
  местного теплового планирования, а если его нет — по умолчанию: для
  муниципалитетов **свыше 100 000 жителей — с 30.06.2026**, для
  муниципалитетов **до 100 000 жителей — с 30.06.2028**. **Сегодня —
  22.08.2026, то есть первый из этих двух порогов уже наступил**: в
  крупных немецких городах (если там ещё не принят собственный план)
  переходное окно уже закрылось, а в малых городах и сёлах, откуда
  типично приходят клиенты небольших Handwerksbetriebe, действует
  запас ещё почти два года. **Для продукта это значит**: подсказка про
  применимые требования к новому отоплению не может быть одной и той
  же по всей Германии — она должна учитывать размер муниципалитета
  клиента (или хотя бы наличие/отсутствие Wärmeplanung, если оно
  известно владельцу/мастеру), а не выдавать усреднённое общегерманское
  правило. Открытый вопрос: свести практическую таблицу "земля/город →
  статус Wärmeplanung" — за пределами разумного объёма одной ревизии,
  отмечаю как задачу на будущее, не изобретаю значения.

**DIN EN 12831 — расчёт теплопотерь как основа подбора, а не формальность:**

- Норма определяет методику расчёта теплопотерь помещения/здания —
  основа подбора мощности любого источника тепла. **Без расчёта по
  DIN EN 12831 не выдаётся почти ни одна субсидия** (BEG — Bundesförderung
  für effiziente Gebäude, в том числе на тепловые насосы) — то есть
  расчёт нужен не только инженерно, но и для того, чтобы клиент вообще
  получил деньги на проект.
- **Экономический аргумент для продукта, не только технический**: по
  данным отраслевого объединения тепловых насосов, точный расчёт по
  норме в среднем снижает выбранную мощность на 15-30% относительно
  расчёта "на глазок"/по эмпирическому правилу (Faustregel) —
  завышенная мощность теплового насоса не просто "с запасом", а прямые
  лишние тысячи евро на оборудование и, для теплового насоса
  специфически, менее эффективную работу (частые короткие циклы
  вместо длинной работы на малой мощности).
- Расчёт по DIN EN 12831 — прямая техническая основа для **Verfahren B**
  гидравлической балансировки (см. ниже): без поквартирного/покомнатного
  расчёта теплопотерь балансировку по методу B выполнить нельзя. Для
  продукта это значит: если клиент просит "просто подключить радиатор"
  без общего расчёта по объекту, приложение должно явно предупреждать,
  что балансировка (обязательная для субсидии и всё чаще для
  гарантийной защиты, см. ниже) в принципе требует этого расчёта как
  предпосылки — то есть одна позиция тянет за собой другую.

**§60c GEG/GModG — гидравлическая балансировка: узкая законная
обязанность и заметно более широкая практическая необходимость (важное
уточнение против первого прочтения источников):**

- **Точная законная область действия** (то, что нашлось после
  нескольких противоречивых первых снипетов и было явно сверено):
  обязанность по **§60c GEG (сохранена в GModG без изменения этой
  нормы)** гидравлически сбалансировать водяную отопительную систему
  после монтажа/переустройства **с целью ввода в эксплуатацию действует
  для зданий от шести квартир/самостоятельных единиц пользования и
  выше**. **Для одно- и двухквартирных домов прямой законной обязанности
  по этой норме сегодня не подтверждено** — это важно, потому что
  большинство клиентов небольшого Handwerksbetriebe в жилом секторе
  типично работают именно с одно-/двухсемейными домами, то есть формально
  вне прямого действия §60c.
- **Но узкая законная обязанность — не то же самое, что "не нужно"**:
  для получения субсидии **KfW 458** на замену отопления (в том числе
  теплового насоса) подтверждение гидравлической балансировки **по
  Verfahren B** требуется независимо от размера здания — без него
  субсидия не выплачивается. Раз практически ни один частный клиент не
  меняет отопление без интереса к субсидии, для продукта разница между
  "законно обязательно" и "обязательно для денег клиента" почти не
  имеет значения на практике — но формулировка в PDF-документе должна
  быть точной (subsidy-requirement, не blanket legal duty для
  одно-/двухсемейного дома), чтобы не создавать юридически неверное
  впечатление у клиента.
- **Ввод в эксплуатацию без баланса и без документа = проверка не
  считается проведённой** — тот же принцип, что уже выведен для
  Erstprüfung в электрике: для систем, где §60c действует напрямую
  (здания от 6 единиц), отопительная система **не может быть введена в
  эксплуатацию без подтверждения балансировки**, а специалист обязан
  письменно задокументировать расчётные данные и передать их
  собственнику. Нарушение обязанностей по §§60a-60c GEG может караться
  штрафом **до €50 000** по §108 GEG — не символическая санкция.

**§14a EnWG — регистрация теплового насоса у сетевого оператора: тот же
паттерн "блокировки ввода в эксплуатацию", но по другому механизму:**

- С 2024 года участие в §14a EnWG обязательно для **управляемых
  потребляющих устройств мощностью подключения свыше 4,2 кВт** — сюда
  прямо входят тепловые насосы (а также приватные Wallbox, сплит-системы
  кондиционирования, накопители). Монтажник обычно сам регистрирует
  устройство как steuerbare Verbrauchseinrichtung в момент ввода в
  эксплуатацию.
- **Без §14a-совместимой регистрации сетевой оператор вправе отказать
  во вводе в эксплуатацию** — формулировка снипетов здесь прямая и
  однозначная, в отличие от некоторых других мест этого документа, где
  источники расходились. В обмен на возможность сетевого оператора
  временно снижать потребление устройства (но не отключать его
  полностью) до 4,2 кВт при угрозе перегрузки сети — постоянно снижается
  сетевой тариф клиента, то есть это не только обязанность, но и
  реальная финансовая выгода, о которой стоит упоминать в подсказке
  приложения как аргумент, а не только как требование.

**Сквозной паттерн продукта, подтвердившийся третий и четвёртый раз
подряд — "ввод в эксплуатацию заблокирован без задокументированного
шага":** электрика (Erstprüfung, DIN VDE 0100-600), сантехника
(Dichtheitsprüfung, DIN EN 806-4/ZVSHK), и теперь отопление сразу по
двум независимым основаниям (гидравлическая балансировка для зданий
от 6 единиц/по факту для субсидии; регистрация теплового насоса по
§14a EnWG) — во всех случаях документ, который генерирует
приложение, не "приятное дополнение", а прямая предпосылка легального
запуска установки. Это уже не совпадение по одной специализации, а
устойчивый паттерн по большей части технических специализаций
документа — стоит закладывать в позиционирование продукта на уровне
"приложение выпускает документы, без которых объект нельзя легально
запустить" как общий тезис, не только применительно к электрике.

**Тепловые насосы — шум, TA Lärm и актуальная судебная практика
2025-2026 (самая свежая практика во всём документе):**

- Действующий ориентир — **Technische Anleitung zum Schutz gegen Lärm
  (TA Lärm)**: в смешанной зоне (Mischgebiet) предельные значения —
  около **60 дБ(A) днём и 45 дБ(A) ночью**, измеряется в 50 см перед
  наиболее затронутым окном соседа. Минимальные расстояния до границы
  участка регулируются не федерально, а строительными нормами земель
  (Landesbauordnung) и заметно различаются — например, порядка **3 м в
  Берлине против 0,5 м в Северном Рейне-Вестфалии** по найденным
  источникам; точная таблица по всем 16 землям сегодня не сведена,
  открытый вопрос.
- **Два свежих решения задают практическую рамку для продукта:**
  - **BGH, Urt. v. 28.03.2025 — V ZR 105/24**: сообщество собственников
    (WEG) не вправе отказать в одобрении установки теплового насоса
    только из-за опасаемого, но не доказанного шума — низкочастотный шум
    до монтажа надёжно не прогнозируется, поэтому отказ на основании
    только предположения неправомерен.
  - **LG Bielefeld, Urt. v. 09.06.2026 — 1 O 310/24**: иск соседей об
    ограничении работы уже смонтированного и работающего теплового
    насоса **отклонён полностью** — назначенный судом эксперт не смог
    подтвердить недопустимую низкочастотную нагрузку, а нормативные
    предельные значения по шуму соблюдались.
  - **Вывод из обоих дел вместе**: суды сегодня требуют не абстрактного
    страха соседей, а измеренного превышения нормы — то есть
    зафиксированный на этапе планирования расчётный уровень звуковой
    мощности устройства и выбранное место установки (расстояние до
    окон, включая спальни соседей) сами по себе становятся
    доказательством добросовестности мастера при монтаже, symmetричным
    тому, как это уже работает для фото скрытых слоёв в других
    специализациях.
  - **Оговорка по методу**: оба дела подтверждены согласованно через
    несколько независимых отраслевых источников (WebSearch-снипеты),
    прямой WebFetch на первоисточники сегодня не выполнялся — тот же
    стандарт уверенности, что применялся к предыдущим судебным делам в
    этом документе.
- **Свежее требование субсидии, отдельное от TA Lärm**: с 01.01.2026
  условие субсидии BEG для теплового насоса включает требование
  безопасного запаса **10 дБ** до предела EU Ecodesign (было 5 дБ) —
  то есть даже формально "тихая по паспорту" модель может не пройти по
  субсидии, если запас меньше нового порога; отдельный от
  соседского спора фактор, который стоит фиксировать в подборе модели
  для клиентов, претендующих на субсидию.
- **Для продукта**: при вводе "тепловой насос" (наружный блок)
  приложение должно запрашивать расстояние до окон соседей/спальни,
  паспортный уровень звуковой мощности устройства и планируемое
  расположение (открытый двор/у стены/между зданиями, где возможен
  резонанс) — и фиксировать это в документе до монтажа, а не
  реагировать на жалобу постфактум.

**Дымоходные системы (газ/масло) — Feuerstättenschau и допуск
Bezirksschornsteinfeger как отдельный, обязательный по закону шаг:**

- Для всех дымоотводящих (топливных) отопительных систем законом
  предусмотрены обязательные **Feuerstättenschau** (осмотр печи/котла,
  раз в **3,5 года**) и **допуск (Abnahme)** новой установки —
  по **Schornsteinfeger-Handwerksgesetz (SchfHwG)**. Это суверенная
  (hoheitliche) задача, закреплена именно за **уполномоченным
  районным трубочистом (bevollmächtigter Bezirksschornsteinfeger)**, а
  не за любой трубочистной фирмой на выбор клиента — отличие, которое
  стоит явно объяснять клиенту, если он предлагает "своего" трубочиста
  для этого конкретного шага.
- **Практическое следствие для продукта**: перед вводом в эксплуатацию
  газового/масляного котла требуется допуск дымохода трубочистом —
  ещё один, третий по счёту в этом разделе, механизм "нет документа —
  нет легального запуска", специфичный именно для топливных систем
  (тепловые насосы этого требования не имеют, что тоже стоит явно
  показывать как разницу при выборе типа отопления).

**Тёплый пол — DIN EN 1264, Aufheizprotokoll и межцеховая ловушка
ответственности (находка дня с прямой связью к уже разобранному
разделу "Плитка" выше):**

- **DIN EN 1264** (пришла на смену прежней DIN 4725 для цементных
  стяжек) регулирует укладку и ввод в эксплуатацию водяного тёплого
  пола, часть 4 — именно процедуру нагрева стяжки.
- **Обязательная выдержка перед началом нагрева**: для цементной
  стяжки нагрев можно начинать **не раньше 21 дня** после заливки —
  это не рекомендация, а обязывающее требование по найденным
  источникам.
- **Двухфазный протокол**: **Funktionsheizen** (функциональный нагрев,
  проверка на отсутствие дефектов) — минимум **7 дней** (3 дня на
  стартовой температуре + 4 дня на максимальной), затем
  **Belegreifheizen** (нагрев до готовности к покрытию, вытеснение
  остаточной влаги) — ещё **7-14 дней** в зависимости от вида стяжки.
  Слишком раннее включение прерывает этот процесс и создаёт риск
  **трещин в стяжке**.
- **Это прямая, юридически острая межцеховая точка стыка с уже
  разобранным разделом "Плитка/камень" (Fliesenarbeiten) выше**:
  Aufheizprotokoll должен быть **передан укладчику покрытия
  (Bodenleger/Fliesenleger)** до начала его работы — по логике ATV DIN
  18365 (Bodenbelagsarbeiten). Именно укладчик покрытия обязан
  убедиться перед началом своей работы, что нагрев проведён по
  правилам и стяжка готова к покрытию — то есть ответственность здесь
  явно передаётся от одной специализации к другой через конкретный
  документ, а не молчаливо предполагается.
- **Самое острое найденное следствие**: кто не ведёт протокол
  полностью и не даёт его подписать, **теряет право на гарантийные
  претензии в случае повреждения — и это касается как заказчика, так
  и исполнивших работу мастеров**, то есть отсутствие протокола вредит
  обеим сторонам одновременно, а не только одной.
- **Вывод для продукта**: это ровно тот случай, где приложение решает
  проблему не одной специализации, а стыка двух (Heizungsbauer и
  Fliesenleger/Estrichleger), причём оба уже отдельно описаны в этом
  документе. Приложение должно уметь: (1) зафиксировать дату заливки
  стяжки как отдельное событие с таймштампом (даже если стяжку
  укладывает не отопленец, а другая бригада), (2) автоматически
  считать и подсказывать самую раннюю разрешённую дату начала нагрева
  (+21 день), (3) вести протокол нагрева по дням с температурой,
  (4) **блокировать позицию "укладка плитки/покрытия поверх тёплого
  пола" в интерфейсе, пока Aufheizprotokoll не отмечен как
  завершённый** — то есть не просто хранить протокол, а использовать
  его как условие для следующего шага в самом рабочем процессе
  приложения. Это первый найденный в документе случай, где логика
  приложения должна явно связывать две ранее независимо описанные
  специализации, а не просто добавлять подсказки внутри одной.

**Технологическая последовательность отопительных работ — что ломается
при нарушении порядка:**
1. **Расчёт теплопотерь по DIN EN 12831** — до подбора мощности
   источника тепла и до гидравлической балансировки, потому что оба
   следующих шага технически опираются на этот расчёт. Пропуск = либо
   завышенная мощность (лишние деньги клиента, менее эффективная
   работа теплового насоса), либо отказ в субсидии позже.
2. **Выбор типа источника тепла с учётом Bestandsschutz/GModG/
   Wärmeplanung** — до заказа оборудования: действует ли требование
   климатически нейтральной квоты для газа/масла в этом
   муниципалитете уже сегодня или ещё нет (см. привязку к дате
   Wärmeplanung выше), нужна ли клиенту вообще замена по закону
   (Havarie/30-летнее правило) или это добровольный выбор.
3. **Монтаж/расширение распределительной системы (радиаторы/тёплый
   пол)** — для тёплого пола: соблюдение шага трубы по EN 1264-3 и
   состава стяжки **до** заливки, потому что после заливки эти
   параметры не исправить без вскрытия пола.
4. **Заливка стяжки (если тёплый пол) — фиксация даты с таймштампом**
   как отдельное событие, от которого отсчитываются 21 день до начала
   нагрева.
5. **Гидравлическая балансировка по Verfahren B** — после монтажа
   всей системы, с документированием расчётных данных; для зданий
   от 6 единиц — обязательное условие ввода в эксплуатацию, для
   меньших объектов — обязательное условие субсидии KfW 458.
6. **Aufheizprotokoll для тёплого пола (если применимо)** — не раньше
   +21 день от заливки, Funktionsheizen → Belegreifheizen, с передачей
   протокола следующей бригаде (Fliesenleger/Bodenleger) до начала её
   работы.
7. **Регистрация теплового насоса по §14a EnWG у сетевого оператора**
   (если применимо) — до включения в постоянную эксплуатацию, иначе
   сетевой оператор вправе отказать во вводе.
8. **Feuerstättenschau/допуск трубочиста** (для топливных систем) —
   до постоянной эксплуатации газового/масляного котла.
9. **Передача заказчику**: расчёт теплопотерь, протокол балансировки,
   Aufheizprotokoll (если тёплый пол), подтверждение регистрации по
   §14a или допуска трубочиста — набор документов разный для теплового
   насоса и для топливной системы, приложение должно предлагать
   правильный набор в зависимости от выбранного типа отопления, а не
   один универсальный список.

**Примеры подсказок:**
- "радиатор монтировать" → тип/мощность по расчёту DIN EN 12831
  (не "на глазок"), боковое/нижнее подключение, включение в общую
  гидравлическую балансировку объекта.
- "тёплый пол" → шаг трубы по EN 1264-3, состав стяжки, **автоматическая
  подсказка даты начала нагрева (+21 день от даты заливки) и запуск
  чек-листа Aufheizprotokoll**, блокировка позиции "укладка покрытия"
  до отметки о завершении протокола.

### Малярные работы (Maler- und Lackierarbeiten)
- VOB/C: **DIN 18363** (Maler- und Lackierarbeiten — Beschichtungen,
  ред. 2019-09) — структура норматива стандартная для VOB/C: Stoffe,
  Ausführung, Nebenleistungen/Besondere Leistungen, Abrechnung.
- **Почему именно эта специализация следующая по приоритету**: она прямо
  продолжает уже расписанный раздел про штукатурку (шаг 6 графа
  "Штукатурка" выше явно ссылался на "Maler-раздел, приоритет на ближайшую
  ревизию") — красят почти всегда поверх чужой (или своей же) предыдущей
  работы, а не в вакууме, поэтому граница ответственности "мой слой
  vs. чужое основание" — источник тех же типов спора, что уже видели в
  штукатурке и плитке (скрытый дефект основания, не видимый в день
  приёмки).
- **Nebenleistungen (входит в цену по умолчанию, отдельно не
  доплачивается)**: шлифовка между слоями (дерево/минеральные основания/
  металл), финальная очистка поверхности перед покраской, подготовка
  образцов цвета/материала для согласования с заказчиком. Леса —
  Nebenleistung, только если рабочая поверхность не выше 3,50 м от уровня
  стояния — выше этой высоты леса становятся отдельно оплачиваемой
  позицией (Besondere Leistung). **Для продукта**: это готовое правило
  для автоподсказки — при вводе "покраска фасад" приложение должно
  спросить высоту работ и не пытаться включить леса >3,5 м в базовую
  цену бесплатно.
- **Кол-во слоёв как норма, не как "мастер на глаз решил"**: по
  умолчанию (если в договоре явно не оговорено иное) ATV DIN 18363
  требует для первой окраски минеральных оснований снаружи трёхслойное
  покрытие (Grund-, Zwischen-, Schlussbeschichtung). Отклонение от этого
  (например, "двух слоёв достаточно") должно быть явно зафиксировано в
  договоре/Nachtrag ДО начала работы — иначе по умолчанию считается, что
  подрядчик должен был сделать три слоя, и недоделанная работа в 2 слоя
  формально является недостатком (Mangel), даже если визуально
  укрывистость выглядит достаточной сразу после высыхания.
- **Классификация красок для интерьера — DIN EN 13300**, даёт готовую
  структуру для выбора качества краски в приложении (по аналогии с
  Q1-Q4 в гипсокартоне, но это отдельная европейская норма, не немецкая
  ATV-классификация):
  - **Deckkraftklasse (укрывистость) 1-4**: класс 1 — контрастное
    отношение ≥99,5% (лучшая укрывистость), класс 2 — ≥98%, класс 3 —
    ≥95%, класс 4 — <95% (нужно больше слоёв на ту же контрастность).
  - **Nassabriebklasse (стойкость к мокрому истиранию) 1-5**: класс 1 —
    самая высокая стойкость, класс 5 — самая низкая; для кухни/коридора/
    часто моемых поверхностей рекомендуется минимум класс 2 (соответствует
    бывшему обозначению "истираемая/scheuerbeständig" по старой DIN
    53778). **Для продукта**: подсказка "покраска кухня/коридор" должна
    предлагать минимум Nassabriebklasse 2, не базовый вариант для спальни.
  - **Glanzgrad (степень блеска) G1-G4**: G1 глянцевый, G2a/G2b
    полуглянцевый/среднего блеска, G3 матовый, G4 глубокоматовый.
- **Классификация красок для фасада — DIN EN 1062** (в отличие от EN
  13300 для интерьера, это отдельная норма для минеральных фасадов):
  - **sd-значение / класс V1-V3** — паропроницаемость (чем меньше
    sd-значение, тем выше паропроницаемость; класс V1 — высокая
    паропроницаемость, sd <0,14 м).
  - **W-значение / класс W1-W3** — водопоглощение (чем меньше значение,
    тем ниже влагопоглощение стены).
  - **Почему это критично для продукта, а не справочная деталь**: именно
    несовпадение этих двух параметров (плотная низкопаропроницаемая
    краска на диффузионно-открытой известковой/силикатной Altbau-стене)
    — механизм скрытого дефекта, описанного ниже в сценарии спора №7.
    Приложение должно уметь спросить "старое основание — минеральное
    диффузионно-открытое или уже запечатано дисперсией?" при вводе
    "покраска фасад/наружная стена" и предупреждать о риске несовместимости,
    а не просто предлагать любую фасадную краску по каталогу.
- Пример подсказки: "покраска стена интерьер" → тип основания (минерал/
  дисперсия старое покрытие), тип краски+грунтовка под пару, класс
  Deckkraft/Nassabrieb по помещению (кухня/ванная = мин. 2), кол-во слоёв.
- Пример подсказки: "покраска фасад" → высота работ (леса >3,5 м —
  отдельная позиция), Untergrundprüfung основания старого покрытия,
  совместимость систем (силикат/дисперсия/известь), sd-/W-класс новой
  краски, стандартные 3 слоя для первой окраски минерального основания.

### Кровля (Dachdeckungs- und Dachabdichtungsarbeiten)

- Пример подсказки: "переукладка кровля черепица" → замер факт. уклона →
  сверка с Regeldachneigung материала → предупреждение о необходимости
  Zusatzmaßnahmen при недоборе, вопрос о высоте конька (леса как отдельная
  позиция почти всегда, порог ниже, чем у малярки), обязательный шаг
  "осмотр стропил/обрешётки после снятия старого покрытия — фото до
  закрытия новым слоем".
- Пример подсказки: "кровля плоская гидроизоляция" → уклон (мин. 2%,
  ориентир 5% для полного исключения застоя), основной + аварийный
  водоотвод, тип гидроизоляционного материала по DIN 18531.

### Плотницкие/деревянное строительство (Zimmer- und Holzbauarbeiten)
- VOB/C: **DIN 18334** (Zimmer- und Holzbauarbeiten, актуальная редакция

- **Почему это следующий приоритет после кровли, не случайный выбор**:

  который в уже расписанном разделе "Кровля" считается данностью
  ("снятие старого покрытия открывает стропила для осмотра"). Для
  нового строительства или полной замены стропил Zimmerer — это
  предыдущий шаг всей цепочки, не отдельная несвязанная специализация.
  Плюс — терраса/навес/Carport — второй по частоте типовой заказ малой
  плотницкой бригады у частного клиента (не только кровельная
  конструкция), с отдельной юридической ловушкой (см. сценарий спора №9
  ниже).
- **Класс прочности пиломатериала — два параллельных стандарта**:
  визуальная сортировка по **DIN 4074-1** (классы S7/S10/S13 для хвойных
  пород) сопоставлена с европейскими классами прочности по **DIN EN 338**
  (C14…C40). Для типового несущего бруса в жилом строительстве —
  **S10 соответствует C24** (самое частое обозначение на стройплощадке),
  **S13 соответствует C30**. Соответствие S7 некоторые вторичные
  источники дают как C16, другие — как C18 — **расхождение между
  источниками не разрешено сегодня, отмечаю как открытый вопрос, не
  выбираю одно значение произвольно**; для продукта это не критично,
  т.к. S7 — низший рядовой класс, редко указывается явно в приложении
  для жилых несущих конструкций (S10/C24 — практический дефолт).
  Технически предварительно высушенный **Konstruktionsvollholz (KVH)** —
  отдельная маркированная категория пиломатериала с определённой влажностью
  (см. ниже), не просто "сухая доска", и соответствие C24 у него обычно
  идёт вместе с этой маркировкой.
- **Влажность при монтаже (Einbaufeuchte) — конкретное числовое требование,
  не общая формулировка "сухое дерево"**: действующая редакция DIN 18334
  (2023-09) требует для конструктивного пиломатериала влажность **u ≤
  18%** на момент монтажа (более строгое требование, чем прежние 20% в
  версии 1998/2005 года) — для видимых/открытых стропильных конструкций
  дополнительно требуется распил через сердцевину (Kernschnitt) и острая,
  не заоваленная кромка заболони в видимых зонах, точность размеров по
  DIN EN 336 (±1 мм). **Для продукта**: это готовая проверяемая цифра для
  чек-листа приёмки материала на объекте (мастер может измерить
  влагомером на месте и зафиксировать значение в протоколе) — расхождение
  с нормой (мокрая, "зелёная" древесина) — измеримый факт, который
  предотвращает будущий спор о короблении/трещинах после усадки, тем же
  способом, что измеримый уклон и группа раствора в уже расписанных
  разделах штукатурки/плитки/кровли выше.
  **Открытый вопрос**: встречается вторичное утверждение (DIN 68800-2), что
  древесина, увлажнённая до ~20% в процессе стройки, должна просохнуть
  обратно до <20% в течение максимум 3 месяцев — эта цифра сегодня взята
  из сниппета, не проверена по первоисточнику DIN 68800-2, отмечаю как
  требующее сверки на следующей ревизии, не как подтверждённый факт.
- **Защита древесины (Holzschutz) — DIN 68800, система классов
  использования (Gebrauchsklassen), актуальная терминология с 2011/2012
  сменила прежние "классы опасности" (Gefährdungsklassen)**. Решающий
  критерий — фактическая влажность древесины в условиях эксплуатации, не
  порода дерева сама по себе:
  - **GK 0** — древесина никогда не подвергается погодным воздействиям
    и не может увлажниться (внутри отапливаемого сухого помещения) —
    химическая защита не нужна в принципе.
  - **GK 1** — постоянно сухо, защищено от погоды, но теоретически
    возможен контакт с насекомыми (например открытый, но защищённый от
    осадков видимый Dachstuhl в неотапливаемом чердаке).
  - **GK 2** — периодически может увлажняться, но с хорошей возможностью
    высохнуть (например защищённые от прямого дождя, но не герметично
    закрытые несущие элементы).
  - **GK 3.1 / GK 3.2** — регулярно подвергается погоде (дождь, брызги),
    отличие 3.1 от 3.2 — в степени защиты от обрызгивания и способности
    быстро высыхать (3.1 — например открытые опоры террасы с хорошим
    проветриванием и защитой от прямого затекания; 3.2 — например
    несущие балки настила террасы без защиты от скопления влаги/грязи).
  - **GK 4** — постоянный контакт с землёй или пресной водой (столбы,
    вкопанные прямо в грунт, опоры причалов) — здесь обязательна
    химическая защита древесины (не просто конструктивная), либо
    заведомо стойкая порода дерева.
  **Важный нюанс для продукта, который меняет ответственность за
  проектное решение**: с текущей редакцией DIN 68800-1 назначение
  элемента конструкции конкретному классу использования — обязанность
  планировщика/проектировщика (с письменным обоснованием), а не
  "как всегда делал мастер на глаз" — то есть если приложение предлагает
  голосовому вводу "терраса деревянная" готовый класс GK по умолчанию, это
  не просто удобная подсказка, а фактически проектное решение, которое
  должно быть зафиксировано в документе как явный выбор, а не скрытая
  логика приложения — иначе при споре о преждевременном гниении настила
  неясно, кто отвечал за этот выбор. **Точную табличную привязку GK 3.1
  vs 3.2 к конкретным типам узлов террасы у меня сегодня нет по
  первоисточнику (страницы baunetzwissen.de/holzfragen.de/
  greifswalder-zimmerer.de недоступны напрямую через egress-прокси,
  данные из сниппетов поиска) — отмечаю как требующее сверки по
  первоисточнику на следующей ревизии, использовать с осторожностью как
  ориентир, не как точную норму.**
- **Nebenleistungen по DIN 18334 (включено в цену по умолчанию)**: как и
  в малярных работах (см. выше) — монтаж/демонтаж/содержание лесов для
  собственных работ, если рабочая площадка не выше **3,50 м** от уровня
  стояния (тот же порог, что у Maler-, заметно выше, чем 2 м у
  Dachdecker- Nebenleistung — логично: кровельщик почти всегда работает
  на скате крыши, зимеру чаще достаточно приставной лестницы/помоста при
  сборке каркаса на земле или невысоких конструкциях). Особая защита от
  погоды/климата помещения (Wetterschutz, временное укрытие материала от
  дождя) — **Besondere Leistung** (отдельно оплачивается), если не служит
  исключительно защите собственной уже смонтированной работы — **для
  продукта**: это готовое правило для подсказки "монтаж стропил" в дождливый
  сезон — временное укрытие штабеля бруса или уже смонтированного, но ещё
  не закрытого кровлей каркаса, от дождя — законный повод для отдельной
  позиции, не подразумеваемая часть базовой цены.
- Пример подсказки: "стропила монтировать" / "новый дачстуль" → класс
  прочности бруса (по умолчанию S10/C24), влажность на момент монтажа
  (чек влагомером, порог 18%), для видимых конструкций — Kernschnitt и
  точность DIN EN 336, вопрос про временное укрытие от дождя при
  многодневном монтаже без немедленного закрытия кровлей.
- Пример подсказки: "терраса деревянная настил" / "навес" / "carport" →
  порода дерева и класс использования GK (по контакту с землёй/влагой),
  тип крепления (винты некоррозионные для наружного GK3-4), явный вопрос
  "конструкция закреплена стационарно с фундаментом/зданием или
  демонтируемая" — это не техническая деталь, а прямой юридический
  переключатель гарантийного срока (см. сценарий спора №9 ниже) — должен
  попасть в документ явно, а не быть домыслен постфактум.

### Металлоконструкции (Metallbauarbeiten) — проработано 2026-08-19

- **Почему это следующий приоритет после Zimmer-/Holzbau, не случайный
  выбор**: перила и ограждения (Geländer) балконов/террас/наружных
  лестниц — типовой сопутствующий заказ ровно у тех же специализаций,
  что уже расписаны выше (терраса от зимера часто получает металлическое
  или стеклянное ограждение, кровельщик при переукладке иногда меняет и
  примыкающее ограждение слухового окна/выхода на плоскую кровлю), то
  есть это не новая изолированная ветка каталога, а логическое продолжение
  уже покрытых сценариев объекта.
- **VOB/C: DIN 18360** (Metallbauarbeiten, действующая редакция 2019-09,
  структура норматива стандартная для ATV — 6 частей: 0 Hinweise für das
  Aufstellen der Leistungsbeschreibung, 1 Geltungsbereich, 2 Stoffe/
  Bauteile, 3 Ausführung, 4 Nebenleistungen/Besondere Leistungen,
  5 Abrechnung). Область действия — металлические конструкции, в том
  числе в сочетании с другими материалами (например ограждение со
  стеклянным заполнением в металлической раме).
- **Маршрутизация "металл vs. другая специализация" — та же логика
  разделения границ, что уже применялась выше для ступеней/кровли**: DIN
  18360 прямо НЕ распространяется на несущий стальной каркас здания
  (**DIN 18335** Stahlbau), кровельные металлические работы вроде
  водостоков/обшивки (**DIN 18339** Klempnerarbeiten), фурнитуру
  (**DIN 18357** Beschlagarbeiten), рольставни (**DIN 18358**
  Rollladenarbeiten), подвесные потолки из металлопрофиля (**DIN 18340**
  Trockenbau), вентилируемые фасады (**DIN 18351**), покрытие/окраску
  металла (**DIN 18363** Maler-/Lackierarbeiten) и антикоррозийную защиту
  как отдельную позицию на уже смонтированных стальных конструкциях
  (**DIN 18364** Korrosionsschutzarbeiten an Stahlbauten). **Для
  продукта**: если голосовой ввод называет материал (сталь несущая/
  водосток/фурнитура), приложение должно маршрутизировать позицию в
  правильную специализацию, а не сваливать всё металлическое в одну
  корзину "Metallbau" — та же ошибка, которой уже избегали при
  маршрутизации ступеней (штучная брусчатка → 18318, натуральный камень →
  18332, плитка → 18352).
- **Редакция 2019-09 против прежней 2012 — что изменилось (снипет через
  поиск, требует сверки по первоисточнику на следующей ревизии)**:
  предоставление статического расчёта конструкции и компенсация
  существенной неровности/отклонения размеров основания сверх допусков
  **DIN 18202** переведены из подразумеваемой части основной услуги в
  явную **Besondere Leistung** (отдельно оплачивается) — практический
  вывод для продукта: если основание под установку перил/ворот
  неровное сверх обычного допуска, это законный повод для отдельной
  позиции, не бесплатная подгонка мастером по факту.

**Высота ограждения (Absturzsicherung/Umwehrung) — не DIN 18360, а
Landesbauordnung, и это критично для продукта, не техническая деталь:**

- **Разграничение стандартов, чтобы не перепутать источник нормы (та же
  логика "ATV = договорной слой, отдельный стандарт = техническое
  исполнение", что уже использовалась у плитки/кровли выше)**: конкретная
  высота ограждения не устанавливается ни самой DIN 18360, ни
  ATV-стандартом вообще — это вопрос строительного надзорного права.
  **DIN 18065** регулирует лестницы (Treppen) и, в частности, высоту
  поручня/перил именно у лестничного марша; общая обязанность иметь
  ограждение и его высота у балконов/террас/краёв перекрытий — предмет
  **Landesbauordnung (LBO)** каждой отдельной федеральной земли,
  формально основанной на модельном законе **Musterbauordnung (MBO)**, но
  не идентичной ему во всех 16 землях. При расхождении между DIN 18065 и
  конкретной LBO действует LBO (несколько независимых источников
  согласованно подтверждают этот приоритет).
- **Порог, с которого ограждение вообще обязательно**: источники
  расходятся — один снипет называет общий порог "более 1,00 м перепада
  высоты", другой — диапазон "50-100 см в зависимости от земли". **Не
  выбираю одно значение произвольно — открытый вопрос, требует прямой
  проверки текста конкретной LBO той земли, где находится объект, а не
  единого числа для всей Германии.**
- **Требуемая высота ограждения там, где оно обязательно — расхождение
  между источниками подтверждено по нескольким независимым сайтам, не
  случайная ошибка одного источника**: часть источников называет базовый
  порог **0,90 м** при перепаде высоты до 12 м и **1,10 м** свыше 12 м
  (это же значение согласованно встречается и в контексте DIN 18065 для
  лестничных ограждений); другая часть источников называет **0,80 м** как
  базовый порог по MBO при перепаде до 12 м, с **0,90 м** свыше. При этом
  конкретные земли явно отличаются друг от друга по нескольким
  независимым источникам: **Берлин — 80 см**, **Бранденбург — 90 см**,
  **Баден-Вюртемберг — 100 см** (все при перепаде высоты до 12 м, то есть
  в этом же классе перепада три соседние земли дают три разных числа).
  **Вывод для продукта, который не зависит от того, какое из
  расходящихся чисел точное**: точное пороговое значение высоты
  ограждения — не константа приложения, а параметр, зависящий от
  федеральной земли объекта, и должен запрашиваться/храниться как
  явный факт объекта (адрес объекта уже так или иначе есть в
  приложении), а не браться единым дефолтом "0,90 м, как обычно" для
  всей Германии — ошибка здесь не косметическая, а мера конкретной
  безопасности человека и предмет прямой ответственности монтажника.
  Сведение точной таблицы "земля → порог требования / требуемая высота"
  по первоисточникам (тексты 16 LBO) — открытая задача на одну из
  следующих технических ревизий, слишком объёмная для одного дня, но
  явно обозначенная как нужная, не забытая.
- **Просветы (Sprossenabstand) — правило "шара 12 см"**: там, где
  ограждение доступно детям (жилые дома, включая частные балконы/
  террасы — почти весь адресный сегмент приложения), между вертикальными
  элементами ограждения (и в зоне до определённой высоты от пола) не
  должен проходить шар диаметром 12 см — правило встречается согласованно
  в нескольких независимых источниках, включая параллель со стандартом
  стадионов (DIN EN 13200-3) и швейцарской нормой (тот же принцип, другая
  юрисдикция). **Для продукта**: голосовой ввод "перила/ограждение
  балкон" в жилом доме должен по умолчанию предполагать это требование
  включённым (не опциональным), а не полагаться на то, что мастер сам
  вспомнит про детей в доме, которых на момент заказа может и не быть, но
  которые появятся или будут в гостях позже.
- **Горизонтальная нагрузка на поручень** — по **DIN EN 1991-1-1**
  (Eurocode 1, нагрузки на конструкции): ориентир **0,5 кН/м** для жилых
  зданий, **1,0 кН/м** для мест с публичным доступом — это конструктивное
  требование к самому ограждению (толщина стойки, крепление), не только к
  его высоте, и объясняет, почему "любая красивая металлическая рама"
  технически не равнозначна сертифицированному ограждению.

**Коррозионная защита — DIN EN ISO 12944, категории C1-C5:**

Наружное ограждение — конструкция, которая обязана простоять снаружи
десятилетиями без переделки, поэтому выбор класса антикоррозийного
покрытия — не декоративная опция, а инженерное решение с прямым
следствием для гарантии. Категория подбирается по фактическому
окружению объекта, не берётся одна "стандартная":
- **C3** (умеренная) — сельская местность и город с умеренным
  загрязнением воздуха, низкая концентрация соли, 10-20 км от моря —
  типичный случай для большинства немецких частных объектов вдали от
  побережья.
- **C4** (сильная) — промышленные зоны, бассейны, прибрежные районы с
  умеренной концентрацией соли, 3-10 км от моря.
- Дополнительно — срок службы покрытия делится на классы: низкий (2-5
  лет), средний (5-15 лет), высокий (от 15 лет) — комбинация категории
  окружения и требуемого срока определяет конкретную систему покрытия
  (например оцинковка + порошковая окраска для C3/средний срок).
**Для продукта**: подсказка "ограждение/перила снаружи" должна спросить
тип окружения объекта (обычная сельская/городская зона, промзона,
прибрежная зона) и предполагаемый срок службы — не предлагать один
универсальный "антикоррозийный слой" без указания класса, потому что
неверно подобранный класс — это не эстетическая недоделка, а причина
преждевременной ржавчины и обоснованной рекламации через несколько лет,
тот же механизм скрытого дефекта, что уже неоднократно встречался выше
(штукатурка/плитка/кровля) — только здесь дефект прогрессирует медленно и
видимо, а не скрыт под слоем.

**Стеклянное ограждение (Ganzglasgeländer) — частый выбор при
обновлении балкона, отдельная материаловедческая ветка:**

- **DIN 18008-4** (Glas im Bauwesen — Absturzsichernde Verglasungen),
  заменил прежний отраслевой ориентир TRAV. Обязательное требование —
  **VSG** (Verbundsicherheitsglas, многослойное стекло со стойкой к
  разрыву плёнкой между слоями) — при разрушении осколки удерживаются
  плёнкой, и конструкция сохраняет остаточную несущую способность вместо
  мгновенного обрушения.
- **Две принципиально разные категории конструкции, с разным требованием
  к самому стеклу — это развилка, которую голосовой ввод должен явно
  прояснить, а не угадывать**:
  - **Категория A** (безрамное, "цельностеклянное" ограждение) — стекло
    само по себе несёт всю нагрузку без отдельного поручня/каркаса —
    требует VSG на основе **TVG** (термически упрочнённое стекло),
    потому что VSG на основе обычного ESG не обеспечивает достаточной
    остаточной несущей способности для этого случая.
  - **Категория B** (стекло как заполнение в раме/между стойками, с
    отдельным несущим поручнем/каркасом) — стекло само нагрузку не
    несёт, здесь достаточно VSG на основе **ESG** (закалённое стекло).
  Практическая разница — не только цена материала, но и то, какая
  конструктивная система вообще допустима. **Для продукта**: голосовой
  ввод "стеклянное ограждение балкона" должен явно спросить "с рамой/
  поручнем или безрамное (только стекло)" одним из двух вариантов, а не
  предлагать одну обобщённую позицию "стекло для ограждения" — иначе
  риск заказать/посчитать не тот тип VSG для конструктивной роли, которую
  стекло реально играет.
- Типовые толщины для частных балконов/террас на практике — часто около
  **16,76 мм** VSG (например 2×8 мм ESG + плёнка) для категории B и более
  толстые пакеты (например около **21,52 мм**, 2×10 мм) для более высоких
  нагрузок/пролётов или категории A — это ориентир по практике отрасли из
  вторичных источников, не жёсткая норма самого DIN 18008, конкретная
  толщина всегда результат расчёта под конкретный пролёт/нагрузку.

**Bestandsschutz при замене ограждения — прямое основание нового
сценария спора №11 ниже:**

Старое, не соответствующее сегодняшним нормам ограждение (более низкое,
с более широкими просветами, чем сегодняшнее правило "шара 12 см") может
законно оставаться на месте под защитой **Bestandsschutz**, пока
выполняется только его обслуживание/покраска/точечный ремонт. Но при
**полной замене** ограждения или существенной конструктивной переделке
(в том числе вынужденной — например демонтаж при утеплении фасада)
Bestandsschutz прекращается, и новая конструкция обязана соответствовать
**сегодняшним** нормам высоты/просветов/нагрузки, а не воспроизводить
старые параметры "как было". Это создаёт ровно тот тип скрытого,
предсказуемого объёма работ, который уже разбирался в сценариях спора
№6-8 (Prüf- und Hinweispflicht) — только здесь предупреждать нужно не о
техническом браке, а о том, что "просто перила заменить" почти всегда
означает "перила заменить на более высокие/с другим шагом стоек", и это
не входит в цену "как старое", если явно не оговорено.

- Пример подсказки: "перила балкон заменить" → федеральная земля объекта
  (для выбора требуемой высоты — открытый вопрос по точным числам, см.
  выше), проверка правила "шара 12 см" при доступе детей, класс
  коррозионной защиты по окружению (C3/C4) и требуемому сроку службы,
  материал заполнения (металл сплошной/стекло с рамой Kat.B/стекло
  безрамное Kat.A), явное предупреждение "старая высота/просвет ≠
  разрешено воспроизвести 1:1 при полной замене — Bestandsschutz не
  переносится".

## Реальные сценарии споров (документация должна их закрывать)

Найдено реальными кейсами/консультациями (Verbraucherzentrale, судебная
практика):
1. **"Я не соглашался на такую цену"** — по §650b BGB обе стороны должны
   пытаться согласовать цену Nachtrag до начала работ; спор смещается на
   то, что считается "angemessen" (адекватной) наценкой. **Важное
   уточнение области действия (найдено 2026-08-18, ранее в документе не
   было — это может менять юридическую логику для БОЛЬШИНСТВА заказов
   приложения, не деталь)**: §650b BGB — это не общая норма про любой
   Nachtrag, а действует только внутри режима **Bauvertrag по §650a
   BGB** (создание/снос/переустройство здания или внешнего сооружения,
   либо работы по его обслуживанию/ремонту "von wesentlicher Bedeutung"
   для конструкции/сохранности/пригодности здания). По независимым
   юридическим источникам (rechtsanwalt-krau.de, buzer.de, juraforum.de,
   согласованно) обычные небольшие ремонтные/обслуживающие работы —
   прямо приведённые примеры: **"заделка штукатурки" (Ausbessern von
   Putz), "замена отдельных черепиц", "покраска"** — считаются
   второстепенным обслуживанием (untergeordnete Erhaltungsmaßnahme) и
   **НЕ подпадают под понятие Bauvertrag**, то есть остаются обычным
   Werkvertrag по §631 ff. BGB без 30-дневного механизма Anordnungsrecht
   §650b. Это ровно тот класс небольших доп. работ, который приложение
   чаще всего фиксирует (например "нашли ещё пару м² осыпавшейся
   штукатурки рядом", "клиент попросил докрасить откос") — то есть для
   заметной доли реальных Nachträge в приложении **§650b вообще не
   применяется**, действует простое правило оферта/акцепт (§145 ff. BGB)
   и восполняющая норма **§632 Abs. 1-2 BGB**: если по обстоятельствам
   работа однозначно ожидалась не бесплатно (для профессионального
   мастера — почти всегда так), но цена явно не согласована, действует
   *обычная (ortsübliche) цена* за такую работу — заметно более слабая
   переговорная позиция для мастера, чем прямо согласованная и
   подписанная цена, потому что теперь предметом спора становится, что
   считать "обычным". **Для продукта**: это дополнительный, а не
   ослабляющий аргумент в пользу механики приложения — независимо от
   того, применяется ли §650b формально, явная фиксация цены и подписи
   на месте всегда выгоднее мастеру, чем полагаться на восполняющую
   норму §632 или на переговорный механизм §650b (который к тому же
   часто вообще не относится к этому типу заказа). Открытый вопрос:
   точная граница "untergeordnete Erhaltungsmaßnahme" vs. "wesentliche
   Bedeutung" для среднего по размеру Nachtrag (не заделка одной трещины,
   но и не капитальный ремонт) — оценочная, не имеет числового порога в
   норме; для приложения практический вывод один и тот же в обоих
   случаях (фиксировать явно), поэтому не блокирует продукт, но требует
   юридической консультации перед публичными формулировками в
   маркетинге ("мы работаем по §650b BGB" было бы неточным обобщением).
2. **"Это вообще не заказывали"** — подрядчик несёт бремя доказательства,
   что доп. работа заказана уполномоченным лицом. Реальный кейс (Мюнхен):
   иск отклонён из-за отсутствия доказательства заказа доп. подключения
   стиральной машины.
3. **"Это должно было входить в изначальный объём"** — реальный кейс:
   клиенту доначислили €700 (6%) за "забытую" покраску ставен на смету
   €11500 — Verbraucherzentrale подтвердила законность в рамках допуска
   15-20% (до 25% по отдельным решениям) для Kostenvoranschlag, но было
   бы неоплачиваемо при подписанном фикс-прайс договоре.
4. **"Качество не то, что согласовали"** — бремя доказательства у клиента,
   но если клиент саботирует совместную приёмку/документирование —
   бремя доказательства переходит на его сторону (Beweislastumkehr).
5. **Ловушка финальности Nachtrag** — если Nachtrag принят без явной
   оговорки, он считается финальным — связанные расходы, не оговорённые
   при подписании, потом не взыскать.
6. **Скрытый дефект проявляется уже после сдачи работ (найдено
   2026-08-13)** — типично для штукатурки/плитки/наружных работ: брак
   из-за нарушенной технологии (пропущенный Vorspritzer, отсутствие
   уклона на террасе/ступенях, гидроизоляция после плитки вместо до)
   визуально незаметен на приёмке и проявляется через месяцы (после
   первой зимы — растрескивание от мороза; после начала активной
   эксплуатации — отслоение). К этому моменту исполнитель уже не
   присутствует, а заказчик не помнит подробностей монтажа. Смежный,
   но не идентичный правовой сюжет — "дело о плитке" **BGH, Urt. v.
   21.12.2011 — VIII ZR 70/08 (NJW 2012, 1073)**: спор о том, покрывает
   ли Nacherfüllung демонтаж бракованной и монтаж новой плитки, когда
   сам материал (не работа) оказался дефектным, и вправе ли продавец
   отказать из-за "абсолютной непропорциональности" затрат (в деле —
   ремонт на ~€3300 против стоимости бездефектной плитки, порог
   ~150%). **Важная оговорка**: это дело о договоре купли-продажи
   (Kaufrecht/Verbrauchsgüterkauf) — покупатель сам купил бракованную
   плитку в магазине, а не о договоре подряда мастера
   (Werkvertragsrecht, §633 BGB и далее), поэтому это не прямой
   прецедент для типичного случая приложения ("мастер сам закупил и
   положил плитку по договору подряда") — тот случай регулируется
   другой линией норм. **Не подставляю сюда несуществующий кейс по
   Werkvertragsrecht — это открытый вопрос, нужно проверить отдельно
   на следующей ревизии** (например аналог для строительных
   материалов в подряде, тип "дело о черепице" BGH VII ZR 46/17,
   упоминается в отраслевых источниках, но сам текст решения сегодня
   не проверен — не привожу как факт, пока не подтверждено).
   **Вывод для продукта, который не зависит от исхода конкретного
   дела**: чем важнее для приложения фиксировать в момент выполнения
   работы измеримые технические параметры, которые суд позже не
   сможет оспорить как "со слов" — конкретное значение уклона,
   выбранная группа раствора/клея, факт нанесения гидроизоляции до
   укладки (с фото ДО закрытия слоя следующим), а не только финальное
   фото готового результата. Показывает, что фото "было" и "стало" на
   каждом скрытом переходе технологии — это не украшение PDF, а
   единственное доказательство, которое выживает, когда дефект
   проявляется через полгода-год.
7. **Несовместимость систем покрытия при покраске поверх старой отделки
   (найдено 2026-08-14)** — маляр наносит новый слой поверх старого
   покрытия, не выяснив его тип (частый случай Altbau-реновации: старая
   минеральная известковая/силикатная краска против новой дисперсионной
   плёнки, или наоборот). Дефект не виден сразу — проявляется через
   месяцы как пузыри/отслоение, в тяжёлых случаях как задержка влаги в
   стене и риск плесени внутри конструкции. Отличие от сценария 6 (там
   — пропущенный шаг в СВОЕЙ операции, например гидроизоляция): здесь
   спор о том, кто отвечает за скрытое несоответствие ЧУЖОГО основания,
   которое не было явно проверено и задокументировано перед началом
   работы. Профессиональная обязанность мастера — проверить основание и
   явно предупредить заказчика при сомнении (Prüf- und
   Hinweispflicht). **Правовая основа закрыта 2026-08-18 (ранее была
   открытым вопросом)**: для обычного, не-VOB Werkvertrag это не
   отдельная норма, а выводится из **§§631, 633 Abs. 2 BGB** — из самой
   обязанности изготовить работу без недостатков (Herstellungspflicht);
   проверка пригодности вводных данных/оснований заказчика для
   изготовления функционально пригодного результата — часть этой
   договорной обязанности, откуда прямо следует обязанность
   предупредить, если у квалифицированного мастера возникают сомнения в
   пригодности вводных условий (комментарий Prütting/Wegen/Weinreich к
   §633 BGB, раздел "Prüf- und Hinweispflicht", через Haufe-Kommentar).
   Независимо это же подтверждается через **§242 BGB (Treu und
   Glauben)**: правила VOB/B §3 Nr.3 / §4 Nr.3 про Bedenkenanmeldung
   рассматриваются судами не как специальная привилегия VOB-договоров, а
   как конкретизация общего принципа добросовестности — поэтому
   действуют и в чистом BGB-договоре (OLG Celle; независимо
   подтверждено юридической статьёй rae-ott.de с характерным названием
   "Auch im BGB-Werkvertrag müssen Bedenken angemeldet werden").
   **Правовое следствие для мастера**: если обязанность предупредить
   выполнена (заявлено письменно/задокументировано ДО продолжения
   работ), это создаёт самостоятельное основание, освобождающее от
   ответственности за недостаток (Exkulpation) — даже если причина
   дефекта не в его собственной работе, а в чужом основании/материале
   заказчика/предыдущей бригаде. Бремя доказательства, что
   предупреждение действительно было сделано, лежит на мастере (не на
   заказчике) — что прямо подтверждает уже сделанный в этом документе
   вывод: фото+письменная фиксация находки нужны не для красоты
   PDF, а потому что без них у мастера при споре просто нет
   доказательства выполненной обязанности. **Оговорка по методу**:
   найдено через WebSearch (снипеты Haufe-Kommentar
   Prütting/Wegen/Weinreich к §633 BGB и §631 BGB "Nebenpflichten", плюс
   независимая статья rae-ott.de; egress-прокси заблокировал прямой
   доступ к haufe.de, dejure.org, gesetze-im-internet.de и
   bauhandwerk.de сегодня, как и в прошлых ревизиях) — согласованность
   формулировки (§§631, 633 Abs.2 как основа + §242 как параллельное
   обоснование для BGB-случая) в двух независимых источниках даёт
   разумную уверенность, но полный текст авторитетного комментария не
   поднимался напрямую, точную формулировку рекомендуется свести с
   юристом перед публикацией юридических текстов в приложении/на сайте.

8. **Гнилые стропила/обрешётка обнаружены при переукладке кровли
   (найдено 2026-08-15)** — классический сценарий именно для кровельщика:
   старое покрытие снято, под ним видны прогнившие/повреждённые
   жучком-точильщиком стропила или обрешётка, которых не было видно на
   момент осмотра/заключения договора (крыша была закрыта старым
   покрытием). **Ключевой юридический нюанс, отличающий этот сценарий от
   сценария 6-7**: само обнаружение дефекта основания НЕ создаёт у
   кровельщика автоматической обязанности бесплатно его устранить — ремонт
   несущей конструкции не входит в объём договора "переукладка кровли",
   если это не было отдельно оговорено. Но у кровельщика есть встречная
   обязанность — **Bedenkenanmeldung/Prüf- und Hinweispflicht** (для
   VOB-договоров формально закреплена в §4 Abs.3 VOB/B; для обычных
   BGB-Werkverträge — та же правовая основа, что уже закрыта в сценарии 7
   выше: **§§631, 633 Abs. 2 BGB** (часть договорной обязанности
   изготовить пригодный результат) плюс параллельно — **§242 BGB
   Treu und Glauben**, поскольку правило VOB/B §4 Abs.3 рассматривается
   как конкретизация общего принципа, а не привилегия только VOB-
   договоров): заявить заказчику о находке
   письменно, желательно до продолжения работ, и получить согласие на
   доп. объём и цену. Если кровельщик, увидев проблему, молча продолжает
   и закрывает её новым покрытием — риск дефекта (в том числе того, что
   проявится через годы — сгнившая уже новая обрешётка из-за
   недостаточной несущей способности старых стропил) переходит на него,
   даже если первопричина была не его виной. Обратная ошибка (реже, но
   тоже встречается) — недобросовестное завышение объёма "нашли гниль
   везде" без фотодоказательства конкретного места и площади поражения,
   что не выдерживает проверки при оспаривании клиентом.
   **Вывод для продукта**: это ровно тот момент, где голосовой ввод на
   объекте ("нашли гниль на стропиле") должен форсировать не просто
   добавление позиции в смету, а обязательную последовательность:
   фото повреждения с привязкой к конкретному месту крыши → короткое
   текстовое описание находки → отправка клиенту с ценой доп. работы →
   явное согласие/подпись клиента ДО того, как кровельщик закроет проблему
   следующим слоем (Unterspannbahn/обрешётка). Без этой цепочки Nachtrag
   на ремонт стропил рискует не удержаться как в переговорах с клиентом,
   так и (в худшем случае) в суде — не потому что работа не была нужна, а
   потому что не зафиксирован момент обнаружения и согласования ДО
   продолжения работ.

9. **"Терраса/навес/Carport — не "Bauwerk", гарантийный срок не 5, а
   2 года" (найдено 2026-08-16, отдельный тип спора от сценариев 6-8 —
   не о скрытом дефекте технологии, а о том, какой закон вообще
   применяется)** — по §634a Abs. 1 BGB срок давности претензий по
   недостаткам работы **на "Bauwerk" (строение/сооружение) — 5 лет**, а
   для прочих работ — **2 года**. Мастер, который считает "я строю на
   улице — значит, 5 лет гарантии, как обычно на стройке", может
   ошибаться в обе стороны — это не автоматика, а вопрос конкретных
   фактов монтажа, и суды решали в обе стороны на очень похожих
   фактах:
   - **LG Düsseldorf, Urt. v. 5.3.2012 — 5 O 38/10**: деревянная терраса
     52 м² из Bangkirai, элементы скручены между собой болтами, но НЕ
     жёстко связаны со зданием/фундаментом — демонтаж занимал 1,5-2 дня
     простым откручиванием и вывозом элементов. Суд: это НЕ Bauwerk в
     правовом смысле → применяется короткий 2-летний срок давности
     (§634a Abs.1 Nr.1 BGB), не 5-летний.
   - **OLG Düsseldorf, Urt. v. 25.4.2019 — 5 U 91/18** (тот же
     апелляционный округ, другой состав фактов): терраса, уложенная
     плиткой в растворное основание (Mörtelbett) поверх существующей
     бетонной плиты, с примыканием к стене здания и гидроизоляцией —
     здесь дефект примыкания вызвал протечку воды в подвал. Суд: это
     полноценный Bauwerk (работа имеет существенное значение для
     конструкции здания в целом — прочность, сохранность, пригодность
     к использованию) → применяется 5-летний срок (§634a Abs.1 Nr.2
     BGB).
   **Различающий признак между двумя делами, не абстрактный, а
   практический**: жёсткая, трудноразборная связь с землёй/зданием
   (залито в растворное основание, встроено в гидроизоляционный контур
   здания) → Bauwerk, 5 лет. Скручено/собрано без такой связи, разборно
   за 1-2 дня без разрушения → не Bauwerk, 2 года. Это ровно тот же
   параметр, который уже встречался в разделе про Zimmerer/Holzbau выше
   как "явный вопрос: закреплена стационарно или демонтируемая" — там
   он был отмечен как технический факт для выбора класса защиты
   древесины, здесь выясняется, что тот же факт одновременно определяет
   юридический срок гарантии, то есть это не два разных вопроса, а один
   и тот же факт с двумя разными последствиями.
   **Для продукта**: при вводе "терраса"/"навес"/"carport"/любая
   наружная деревянная или каменная конструкция без интеграции в
   несущую конструкцию здания приложение должно (а) задать явный вопрос
   о способе крепления (винтовое/разборное без фундамента vs. залито/
   забетонировано/встроено в гидроизоляцию здания), (б) исходя из
   ответа — подставить в PDF корректную формулировку гарантийного срока
   (2 или 5 лет), а не единый шаблон "5 лет, как везде на стройке" по
   умолчанию, иначе документ может дать заказчику ложное ощущение более
   длинного срока защиты (или наоборот — мастер зря даёт себе более
   долгую ответственность, чем требует закон, не осознавая этого). Это
   тот редкий случай, где юридически правильный ответ прямо противоречит
   бытовой интуиции "я же строю снаружи на земле — это стройка, значит
   долгая гарантия".

10. **"Клиент промолчал на Nachtrag-предложение, я всё равно доделал —
    он теперь должен платить или нет?" (найдено 2026-08-18)** — очень
    частая бытовая ситуация именно в стиле общения владельца с клиентами
    (WhatsApp/SMS вместо личной встречи): мастер на объекте находит доп.
    объём, отправляет клиенту цену текстом, клиент не отвечает (занят,
    забыл, намеренно тянет), мастер решает не простаивать и доделывает
    работу сам, потом спор — "я не давал согласия на такую цену", хотя
    формально и не отказывался.
    - **Общее правило**: молчание само по себе — это НЕ согласие
      (базовый принцип немецкого договорного права, действует и здесь).
      Простое "не ответил в WhatsApp" не равно "согласился на Nachtrag".
    - **Важное уточнение к сценарию 1 выше**: если исходный договор не
      подпадает под Bauvertrag §650a BGB (см. поправку к сценарию 1) —
      формальный 30-дневный переговорный механизм §650b тут не
      применяется вовсе, регулирует обычная оферта/акцепт-логика.
    - **Но есть значимое исключение, подтверждённое практикой судов**:
      если заказчик не ответил на Nachtrag-предложение, но **допустил
      выполнение работы без возражений** (видел, что работа продолжается,
      не остановил, не запротестовал) — это может расцениваться как
      **конклюдентное (молчаливое через поведение) согласие**, и он
      обязан заплатить по предложенной цене. Опорное решение — **OLG
      Brandenburg, Urt. v. 12.05.2022 — 12 U 141/21**: суд прямо
      сформулировал, что из принципа кооперации, лежащего в основе
      VOB/B, вытекает обязанность заказчика своевременно возразить,
      если он не согласен с ценами в Nachtragsangebot, иначе молчание в
      сочетании с допуском исполнения работы без возражений
      расценивается как согласие с предложенной ценой. **Важная
      оговорка по применимости**: разбираемое дело было
      VOB/B-договором с публичным заказчиком, а не обычным
      BGB-Werkvertrag с частным клиентом (типичный случай владельца) —
      перенос этой логики на частный BGB-договор идёт через тот же общий
      принцип Treu und Glauben (§242 BGB), что уже закрыл открытый вопрос
      про Prüf- und Hinweispflicht в сценариях 7-8 выше, и выглядит
      убедительным по аналогии, но это **не проверенный впрямую для
      частного BGB-договора прецедент — открытый вопрос, отмечаю как
      разумную, но не 100%-но подтверждённую экстраполяцию**, требует
      юридической сверки перед тем, как продукт мог бы формулировать это
      клиенту как гарантию.
    - **Восполняющая норма на случай, если ни явного согласия, ни
      молчаливого допуска толком не было (например клиента вообще не
      было на объекте, когда доделывали)**: §632 Abs. 1-2 BGB — если по
      обстоятельствам работа мастера объективно ожидалась не бесплатно
      (для профессионала — почти всегда), но цена не согласована прямо,
      действует "обычная" (ortsübliche) цена за такую работу. Это
      создаёт право на оплату, но заметно более слабое, чем прямо
      согласованная цена — предметом спора становится "что считать
      обычным", то есть именно то, чего продукт должен избегать.
    - **Вывод для продукта — это прямое обоснование конкретного
      UX-решения, а не общие слова**: приложение не должно поощрять
      "отправил цену и продолжил работать, не дожидаясь ответа" как
      нормальный путь — именно эта модель поведения и создаёт спор
      сценария 10. Правильная механика: (а) при отправке Nachtrag-
      предложения клиенту, который не на объекте, зафиксировать
      timestamp отправки и явно предложить мастеру дождаться ответа
      перед продолжением работы, а не автоматически считать "прошло
      время — можно начинать"; (б) если клиент физически на объекте и
      наблюдает выполнение доп. работы — зафиксировать это как отдельный
      факт (например фото/отметка "заказчик присутствовал на объекте во
      время выполнения доп. позиции, возражений не заявил") — это именно
      та ситуация, где конклюдентное согласие по логике OLG Brandenburg
      потенциально применимо, и её стоит явно задокументировать, а не
      полагаться на "он же видел, все же знают"; (в) если ни явного, ни
      конклюдентного согласия нет — приложение должно явно предупредить
      мастера, что при споре сработает более слабая норма §632
      ("обычная цена"), а не заявленная. Это не про то, чтобы напугать
      мастера бюрократией, а про то, чтобы разница между "я отправил
      сообщение и продолжил, понадеявшись" и "я задокументировал согласие
      ДО того, как закрыл слой/сдал работу" была видна ему в моменте, а
      не только задним числом в суде.

11. **"Просто замените перила на балконе" — Bestandsschutz не переносится
    на новую конструкцию (найдено 2026-08-19, прямое следствие раздела
    Metallbauarbeiten выше)** — частый по формулировке, но юридически
    нетривиальный заказ: старый дом, старое ограждение балкона/наружной
    лестницы ниже и/или с более широкими просветами между стойками, чем
    требуют сегодняшние нормы (было легально на момент постройки — тогда
    действовали другие/никакие числовые требования). Клиент формулирует
    заказ как "замени перила, они заржавели" — то есть как чисто
    техническую замену "один в один", не как модернизацию.
    - **Правовой механизм**: пока ограждение обслуживается/красится/
      точечно ремонтируется, старые (заниженные по сегодняшним меркам)
      параметры защищены Bestandsschutz. Но **полная замена** конструкции
      — это новое возведение, не ремонт существующего, и Bestandsschutz на
      неё не распространяется: новое ограждение обязано соответствовать
      действующей на момент монтажа Landesbauordnung, а не воспроизводить
      старые размеры.
    - **Отличие этого сценария от уже разобранных 6-9**: там дефект
      скрытый (проявляется через месяцы/годы, не виден в момент приёмки).
      Здесь наоборот — несоответствие видно сразу и любому специалисту
      (мастер физически меряет старую высоту рулеткой), поэтому это не
      столько спор о скрытом браке, сколько риск, что мастер **тихо
      воспроизведёт старые, заведомо заниженные параметры**, потому что
      клиент именно об этом попросил и именно за это заплатил по
      согласованной цене — а через какое-то время (падение с балкона,
      проверка при продаже дома, жалоба соседа/управляющей компании)
      обнаруживается, что новая конструкция не соответствует норме,
      несмотря на то что она НОВАЯ, не старая. В этом случае
      Bestandsschutz уже не защищает — новая работа должна была
      соответствовать текущей норме с самого начала, независимо от того,
      что хотел клиент.
    - **Кто отвечает**: собственник объекта несёт базовую ответственность
      за соответствие здания нормам (Verkehrssicherungspflicht), но
      исполняющий монтажник отвечает за ошибки монтажа и применение
      неподходящих материалов/размеров — то есть мастер, который по
      просьбе клиента поставил новое, но заниженное по высоте ограждение,
      не может потом сослаться на "клиент сам так просил" как на полную
      защиту: соответствие норме при НОВОМ монтаже — профессиональная
      обязанность исполнителя, аналогично уже закрытой в сценариях 7-8
      Prüf- und Hinweispflicht (тот же принцип: специалист обязан
      предупредить клиента о несоответствии до того, как молча выполнит
      заказ так, как клиент его сформулировал).
    - **Вывод для продукта**: при вводе "перила/ограждение заменить" (в
      отличие от "покрасить"/"отремонтировать точечно" — там Bestandsschutz
      действует, и это не тот же случай) приложение должно явно спросить
      текущую высоту/просвет старого ограждения (можно голосом с
      рулеткой на месте) и сравнить с требуемым по земле объекта
      значением (см. открытый вопрос выше — точная таблица по землям ещё
      не сведена, но сам факт сравнения "старое ≠ автоматически можно
      повторить" должен быть в продукте с самого начала, даже до того как
      таблица точных чисел будет готова), и зафиксировать в документе
      явно проговорённое решение (новая высота = требуемая по норме, не
      "как было"), а не молчаливое воспроизведение старых размеров по
      умолчанию просто потому, что клиент не попросил про это думать.

12. **"Добавь мне одну розетку" в старом доме — и вдруг это замена всей
    линии (найдено 2026-08-20, прямое следствие раздела Elektro выше)** —
    по бытовой логике заказчика это самая мелкая из возможных работ,
    минутное дело, цена "как за розетку". Фактически в доме с проводкой
    времён классической нулёвки (двухпроводная, без отдельного PE)
    добавление точки может означать замену всей линии до щитка.
    - **Правовой/нормативный механизм, отличающийся от сценария 11 —
      и это принципиально**: в сценарии 11 (перила) работал
      Bestandsschutz строительного надзорного права — старая конструкция
      легальна, пока её не заменили целиком. В электрике **понятия
      Bestandsschutz в нормах DIN VDE вообще нет** (оно из строительного
      права и на электроустановки прямо не переносится). Вместо него
      действует связка правил: (а) действующие нормы не требуют
      принудительно переводить существующие установки с TN-C на TN-S,
      то есть заказчика нельзя обязать модернизировать то, что есть;
      (б) но классическая нулёвка недопустима для новых установок и
      **для расширений** с мая 1973 / апреля 1974; (в) **DIN VDE
      0100-100, раздел 11.2**: норма распространяется на расширение или
      изменение установки **и на те части существующей установки,
      которые этим затронуты (beeinflusst)**. Именно (в) превращает
      мелкую работу в крупную.
    - **Где проходит граница, которую мастер должен уметь объяснить
      клиенту в двух фразах**: **замена** дефектного элемента на новый
      точно той же функции (розетка на розетку) приведения к состоянию
      техники **не требует** — это законно и дёшево. **Расширение**
      (новая точка, новый отрезок цепи) втягивает затронутую часть
      существующей цепи в область действия действующей нормы. Наглядный
      случай — розетка снаружи: цепь должна быть защищена RCD ≤30 мА,
      причём защищён должен быть весь участок вплоть до имеющейся
      розетки, а в двухпроводной цепи это означает замену линии
      целиком, а не добавление автомата в щиток.
    - **Почему это опаснее для мастера, чем обычный Nachtrag**: здесь
      он оказывается зажат между двумя рисками одновременно. Сделать
      "как просил клиент" (подключить новую точку к старой цепи без
      PE/RCD) — это выполнить работу, не соответствующую действующей
      норме, в зоне, где цена ошибки — жизнь, и сослаться потом на
      "клиент просил дёшево" не выйдет (тот же принцип, что уже
      выведен в сценарии 11: соответствие норме при новом монтаже —
      обязанность исполнителя, не заказчика). Отказаться и назвать
      реальную цену — выглядеть в глазах клиента как тот, кто
      "раздувает копеечную работу до тысяч евро", что для малой бригады,
      живущей на сарафане, репутационно дорого.
    - **Вывод для продукта — это, возможно, самый прямой аргумент
      "приложение окупается с первого случая" во всём документе**:
      разница между "розетка за €80" и "замена линии за €600-900" —
      это не спор о качестве, а спор об **объёме, который был известен
      до начала работы, но не был зафиксирован**. Приложение должно при
      вводе "добавить розетку/точку" в старом объекте (а) обязательно
      спросить про существующую систему (есть ли PE, есть ли RCD,
      примерный год проводки) **до** того, как назовёт цену,
      (б) сформировать документ, который показывает клиенту причину, а
      не только сумму — фото открытой распаечной коробки/щитка со
      старой двухпроводной линией плюс короткая ссылка на норму
      работают как объяснение сильно лучше, чем устное "у вас там
      старьё, надо всё менять", и (в) явно развести в документе два
      варианта заказа — "замена один-в-один" (дёшево, законно, но новых
      точек не появляется) и "расширение" (дороже, потому что втягивает
      затронутый участок). Эта развилка должна быть предъявлена
      клиенту как **его** выбор, а не как решение мастера, иначе любая
      названная цена выглядит произволом. **Открытый вопрос для
      владельца**: сталкивался ли он с реакцией клиентов на такое
      объяснение — работает ли ссылка на норму как аргумент, или
      клиента убеждает только фото и цена (это влияет на то, стоит ли
      вообще печатать ссылки на DIN VDE в клиентском PDF или они только
      пугают).

13. **"Электрику в комнату" — заказчик считал по одному объёму, мастер
    по другому (найдено 2026-08-20)** — не спор о качестве и не о
    скрытом дефекте, а **расхождение ожиданий об объёме, спрятанное
    внутри одинаковых слов**. Заказчик говорит "сделай электрику в
    гостиной", имея в виду картинку современной квартиры (розетки у
    каждого предполагаемого места, точки под ТВ/интернет/торшеры);
    мастер считает по минимуму нормы. Оба искренне считают, что
    договорились.
    - **Почему это не просто "надо лучше общаться", а нормируемая
      развилка**: объём в жилом строительстве описан двумя разными
      документами с разным назначением — **DIN 18015-2:2021-10** задаёт
      **минимум** (число цепей по площади квартиры: до 50 м² — 3 цепи,
      свыше 125 м² — 7), а **RAL-RG 678** описывает оснащение **сверх**
      минимума через три ступени (Ausstattungswert 1 — минимум, 2 —
      стандарт, 3 — комфорт), где число розеток и точек зависит от
      размера помещения и выбранной ступени. То есть у "нормального
      объёма" нет одного значения по умолчанию — есть три легитимных
      ответа с кратно разной ценой.
    - **Отличие от уже разобранных сценариев**: в сценарии 3 ("это
      должно было входить") спор о забытой позиции, в сценариях 6-8 — о
      скрытом дефекте. Здесь же **никто ничего не забыл и не сделал
      плохо** — работа выполнена корректно по минимуму нормы, просто не
      та, которую представлял заказчик. Такой спор особенно неприятен
      тем, что мастер объективно прав, а клиент субъективно обманут, и
      обычная защита ("я сделал по норме") не восстанавливает
      отношения — а для бригады, живущей на рекомендациях, потеря
      репутации дороже суммы спора.
    - **Вывод для продукта**: это сценарий, который решается **до**
      работы и полностью в UX, а не в юридической формулировке PDF.
      При вводе "электрика комната/квартира" приложение не должно
      подставлять один объём "как обычно" — оно должно показать
      развилку ступеней оснащения с конкретным числом точек и ценой по
      каждой, дать выбрать и зафиксировать выбор в подписываемом
      документе. Это ровно тот же приём, который в этом документе уже
      применён к классам шпаклёвки Q1-Q4 (Trockenbau) и к количеству
      слоёв краски (DIN 18363) — сделать неявное ожидание явным
      выбором до начала работы. Ценность приёма в электрике выше
      просто потому, что ценовая вилка между ступенями шире.
      **Открытый вопрос для владельца**: какая ступень фактически
      является "ожидаемой по умолчанию" у частных клиентов в его
      регионе — то есть какой вариант приложению стоит показывать
      предвыбранным, чтобы не выглядеть ни дорого, ни скупо.

14. **Скрытая протечка на стыке трубы — плесень проявляется через годы
    (найдено 2026-08-21, прямое следствие раздела Sanitär выше)** — тот
    же класс сценария, что уже разобран для штукатурки/плитки/кровли
    (6-8): дефект монтажа не виден на приёмке и проявляется намного
    позже, когда исполнитель уже не присутствует. Здесь — реальное,
    доведённое до Bundesgerichtshof дело, а не общая логика по аналогии.
    - **Дело**: **OLG Schleswig, Urt. v. 24.10.2008 — 14 U 49/08**,
      подтверждено **BGH, Beschl. v. 02.09.2010 — VII ZR 257/08**
      (жалоба подрядчика на отказ в допуске апелляции отклонена).
      Обстоятельства: через 2 года после сантехнических работ в новом
      доме обнаружена протечка из отводной трубы верхнего этажа —
      причина оказалась в неверно установленном/смещённом уплотнении на
      стыке трубы. Плесневое поражение здания и имущества проявилось
      ещё через 3 года после обнаружения протечки. Заявленный ущерб —
      порядка **€126 000**. Суд: подрядчик нарушил договорную
      обязанность корректно смонтировать уплотнение; если монтаж не
      соответствует признанным правилам техники (anerkannte Regeln der
      Technik), действует фактическая презумпция, что при правильном
      монтаже ущерба не было бы — то есть бремя доказывать обратное
      сместилось на подрядчика.
    - **Отличие от уже разобранного сценария 6 (BGH VIII ZR 70/08,
      "дело о плитке")**: тот случай — про договор купли-продажи
      (Kaufrecht), дефектный материал, купленный самим покупателем, не
      про договор подряда мастера. Это дело — прямой аналог именно
      ситуации приложения: мастер сам смонтировал сантехнику по
      Werkvertrag, дефект — в его собственном монтаже (неверное
      уплотнение), не в материале и не в основании заказчика. То есть
      это первый найденный в этом документе прецедент по
      Werkvertragsrecht именно для скрытого технологического дефекта
      (в отличие от сценариев 6-8, где правовая логика выводилась по
      аналогии/общим принципам, а не из конкретного дела с такими же
      фактами).
    - **Вывод для продукта**: это самое прямое на сегодня подтверждение
      того, зачем приложение должно форсировать фото/протокол опрессовки
      как обязательный, а не опциональный шаг перед тем, как позиция
      "сантехника" считается закрытой и следующая специализация
      (штукатур/плиточник) может продолжать поверх неё. Разрыв между
      причиной (плохое уплотнение на монтаже) и видимым симптомом
      (протечка через 2 года, плесень ещё через 3) — дольше, чем в
      большинстве уже разобранных сценариев 6-8, и сумма ущерба —
      самая крупная из всех найденных до сих пор в этом документе.
    - **Оговорка по методу**: egress-прокси заблокировал прямой доступ к
      обоим источникам (brennecke-rechtsanwaelte.de,
      mein-nachbarrecht.de) и к tab.de — номер дела, дата и обстоятельства
      подтверждены согласованно через WebSearch-сниппеты двух независимых
      доменов, но полный текст решения не поднимался напрямую; тот же
      стандарт уверенности, что уже применён в этом документе к делам
      LG/OLG Düsseldorf про террасы (ревизия 2026-08-16) — разумная, но
      не 100%-но подтверждённая по первоисточнику уверенность.

15. **"Просто добавь WC в подвале" — и вдруг обязательна Hebeanlage за
    отдельные деньги (найдено 2026-08-21, прямая параллель со сценарием
    12 у электрика)** — заказчик формулирует заказ так же обманчиво
    просто, как в сценарии 12 ("добавь одну розетку"): для него это один
    сантехприбор, для мастера — потенциально совсем другой объём и
    цена.
    - **Механизм**: если новая точка слива (WC/душ/раковина) находится
      **ниже уровня подпора (Rückstauebene)**, активная защита
      (**Hebeanlage**) обязательна — это не рекомендация и не апгрейд "на
      всякий случай", а нормативное требование по DIN EN 12056/DIN
      1986-100 (см. раздел Sanitär выше). Разница в цене между "просто
      WC" по ожиданию клиента и WC с обязательной подъёмной станцией —
      часто в разы, ровно та же структура спора, что и в сценарии 12
      (там — "розетка" превращалась в замену всей линии).
    - **Ставка выше, чем кажется клиенту, из-за страховки**: если
      требование пропущено и позже (например при сильном ливне —
      явление, которое, как уже отмечено в разделе про плоскую кровлю
      выше, учащается в немецком климате последних лет) происходит
      подпор канализации в подвал, страховка Wohngebäudeversicherung
      вправе отказать или урезать выплату из-за отсутствия исправной
      Rückstausicherung (см. раздел Sanitär выше). То есть мастер, который
      молча идёт навстречу пожеланию клиента "подешевле, без насоса", не
      просто выполняет технически несоответствующую работу — он ставит
      заказчика перед риском незастрахованного ущерба, о котором клиент
      в момент заказа не думал. Это тот же принцип, что уже выведен в
      сценариях 11-12: соответствие норме при новом монтаже — обязанность
      исполнителя, а не то, что можно молча пропустить по просьбе клиента.
    - **Ловушка "дешёвой" альтернативы**: Fäkalienzerkleinerer (измельчающая
      установка) выглядит для клиента как бюджетный вариант вместо полной
      Hebeanlage, но легально применим только при наличии **второго WC
      выше уровня подпора в этом же здании** — то есть для отдельно
      переоборудованной подвальной квартиры (Souterrainwohnung) без
      другого туалета в доме этот путь закрыт полностью, а не просто
      дороже.
    - **Вывод для продукта**: при голосовом вводе сантехприбора ("WC",
      "душ", "раковина") вместе с указанием "подвал"/"цокольный
      этаж"/"Souterrain" приложение должно **до** называния цены
      спросить высоту точки слива относительно смотрового колодца
      канализации на улице (Rückstauebene) и по умолчанию закладывать
      Hebeanlage отдельной позицией, а не тихо считать по цене обычного
      WC — та же UX-развилка "объём выясняется до цены, не после", что
      уже применена к электрике (сценарий 12) и к уклону ступеней/кровли
      выше.
    - **Открытый вопрос для владельца**: приходилось ли ему объяснять
      клиенту необходимость Hebeanlage после того, как цена уже
      прозвучала как "просто WC", и что убеждало клиента лучше —
      ссылка на норму или на реальный риск отказа страховки при
      затоплении (параллельный открытый вопрос уже задан в сценарии 12
      про электрику — работает ли там и здесь один и тот же тип
      аргумента, или в сантехнике страховой довод убедительнее
      технического).

16. **"Сосед подал жалобу на шум теплового насоса" (найдено 2026-08-22,
    прямое следствие раздела Heizung выше)** — не спор с самим
    заказчиком, а спор, в который заказчик и, косвенно, мастер
    втягиваются третьей стороной — соседом. Тепловые насосы в Германии
    последних лет — один из самых частых источников соседских
    конфликтов именно по шуму, и именно поэтому нашлась самая свежая
    судебная практика во всём этом документе.
    - **Механизм**: наружный блок теплового насоса работает
      непрерывно, в том числе ночью, и воспринимается соседями более
      навязчиво, чем разовый шум. Действующий технический ориентир —
      **TA Lärm**: около 60 дБ(A) днём и 45 дБ(A) ночью в Mischgebiet,
      измеряется в 50 см перед самым затронутым окном соседа.
      Минимальное расстояние до границы участка регулируется
      строительными нормами земель и заметно различается по стране.
    - **Что реально решают суды сегодня**: **BGH, Urt. v. 28.03.2025 —
      V ZR 105/24** — сообщество собственников не вправе заранее
      отказать в установке теплового насоса только из опасения
      будущего шума, если он не доказан. **LG Bielefeld, Urt. v.
      09.06.2026 — 1 O 310/24** — обратная ситуация, уже установленный
      и работающий насос: иск соседей об ограничении работы отклонён
      полностью, потому что нормативные предельные значения
      соблюдались и назначенная судом экспертиза не подтвердила
      недопустимую низкочастотную нагрузку. **Вместе оба дела говорят
      одно и то же**: ни отказ в установке, ни последующий запрет
      эксплуатации не проходят в суде без измеренного, а не
      предполагаемого превышения нормы — то есть решает не мнение
      соседа и не мнение заказчика, а зафиксированные цифры.
    - **Отличие от уже разобранных сценариев**: это первый сценарий в
      документе, где потерпевшей/оспаривающей стороной выступает не
      заказчик и не мастер, а третье лицо — сосед, чьё согласие вообще
      не запрашивалось на этапе заказа. Мастер, который смонтировал
      насос технически корректно, но без записи расстояния до окон
      соседей и паспортного уровня шума устройства, остаётся без
      документа именно там, где решение суда сегодня требует конкретных
      цифр, а не общих слов "мы всё сделали по норме".
    - **Вывод для продукта**: при вводе позиции "тепловой насос
      (наружный блок)" приложение должно фиксировать на этапе
      планирования — до монтажа — расстояние до ближайших окон/спален
      соседей, выбранное место установки и паспортный уровень звуковой
      мощности устройства, включённые в подписываемый документ. Это не
      юридическая формальность "на всякий случай", а ровно тот тип
      доказательства, который по свежей практике 2025-2026 годов
      реально определяет исход соседского спора.
    - **Открытый вопрос для владельца**: приходилось ли ему лично
      сталкиваться с жалобой соседа на смонтированный тепловой насос —
      и если да, помогло ли на практике заранее зафиксированное
      расстояние/паспортный уровень шума, или спор решался иначе
      (например через переговоры до суда).

17. **"Плитка треснула через месяц после укладки поверх тёплого пола" —
    межцеховая ловушка Aufheizprotokoll (найдено 2026-08-22, прямая
    связь между разделами Heizung и Fliesen)** — в отличие от
    большинства уже разобранных сценариев, здесь не один исполнитель, а
    минимум два (Heizungsbauer/Estrichleger и Fliesenleger), и ущерб
    может быть виной любого из них — или обоих сразу.
    - **Механизм**: цементная стяжка над тёплым полом требует не менее
      21 дня выдержки перед началом нагрева, затем обязательный
      двухфазный протокол (Funktionsheizen ≥7 дней, Belegreifheizen ещё
      7-14 дней) — это не рекомендация, а обязывающее требование по
      DIN EN 1264-4. Слишком раннее включение нагрева или слишком
      ранняя укладка плитки поверх недостаточно просохшей стяжки —
      обе ошибки приводят к одному и тому же видимому симптому
      (трещины в стяжке/плитке), но виновата в них разная
      специализация.
    - **Почему это ловушка именно для документации, а не для
      квалификации мастеров**: укладчик плитки/покрытия по логике ATV
      DIN 18365 обязан сам убедиться перед началом работы, что стяжка
      готова к покрытию — но без переданного ему Aufheizprotokoll он
      физически не может это проверить, только поверить на слово. Если
      протокол не велся или не передан, при трещине **обе стороны
      теряют право на гарантийные претензии** — то есть отсутствие
      документа вредит не только заказчику, но и обоим исполнителям
      одновременно, что редкость среди уже разобранных в этом
      документе сценариев.
    - **Отличие от сценариев 6-8, 14 (скрытые дефекты)**: там дефект
      скрыт физически (под облицовкой, под кровлей); здесь дефект
      скрыт **процедурно** — сам факт правильного или неправильного
      порядка/сроков не виден на приёмке вообще, ни на фото готового
      результата, только в протоколе с датами и температурами,
      которого может просто не быть.
    - **Вывод для продукта**: это первый сценарий в документе, где
      решение требует, чтобы приложение **связывало две ранее отдельно
      описанные специализации в один рабочий процесс**, а не просто
      добавляло подсказки внутри каждой по отдельности — фиксация даты
      заливки стяжки как отдельного события, автоматический расчёт
      разрешённой даты начала нагрева (+21 день), ведение протокола по
      дням и **блокировка позиции "укладка плитки/покрытия" в
      интерфейсе**, пока Aufheizprotokoll не отмечен завершённым.
    - **Открытый вопрос для владельца**: работает ли он сам обеими
      специализациями последовательно на одном объекте (тогда стык
      решается внутри одной бригады) или чаще передаёт объект другой
      бригаде/фирме для укладки покрытия — от этого зависит, должен ли
      Aufheizprotokoll в приложении быть просто внутренней записью или
      полноценным документом на экспорт для чужого исполнителя.

**Вывод для продукта**: документ должен явно фиксировать (а) кто заказал
доп. работу и когда, (б) согласована ли цена ДО начала работы (не
постфактум) — включая явное или хотя бы конклюдентное согласие, а не
просто "цена отправлена и клиент не возразил" (сценарий 10), (в) явную
оговорку, если что-то остаётся открытым, (г) для работ со скрытым
технологическим риском (сценарии 6-8) — измеримые технические параметры,
фото промежуточных/позже скрытых слоёв и состояния существующего
основания/конструкции ДО начала своей работы (включая находки вроде
гнилых стропил под старой кровлей — сценарий 8), не только фото готового
результата, (д) для наружных конструкций без однозначной интеграции в
здание (сценарий 9) — явный факт способа крепления, от которого зависит
применимый гарантийный срок 2 vs 5 лет, чтобы PDF не подставлял неверную
формулировку "на автомате", (е) для Nachträge, где Nachtrag-предложение
отправлено дистанционно (не лично на объекте) — явный timestamp отправки
и статус ответа клиента (сценарий 10), чтобы не полагаться молча на
восполняющую норму §632 там, где легко было зафиксировать явное
согласие, (ж) для замены конструкций с нормируемыми параметрами
безопасности (высота/просвет ограждения — сценарий 11) — явное сравнение
"старое значение vs. требуемое по норме" и зафиксированное решение, а не
молчаливое повторение старых размеров только потому, что клиент
сформулировал заказ как "замену как было", (з) для работ в существующей
электроустановке (сценарий 12) — состояние исходной установки (наличие
PE/RCD, тип системы, примерный возраст проводки), зафиксированное ДО
называния цены, и явную развилку "замена один-в-один vs. расширение,
втягивающее затронутый участок", (и) для работ, где норма задаёт только
минимум, а рынок ожидает больше (сценарий 13 — ступени оснащения
электрикой) — зафиксированный выбор объёма из явно предъявленных
вариантов, а не подставленный приложением "обычный" объём, (к) для
сантехнических работ со скрытым соединением/уплотнением (сценарий 14) —
протокол опрессовки с фото ДО закрытия трубы стеной/полом, потому что
разрыв между причиной и проявившимся ущербом здесь подтверждён реальным
делом как самый долгий и дорогой из всех разобранных сценариев, (л) для
новых точек слива в подвале/цоколе (сценарий 15) — явно зафиксированная
высота относительно Rückstauebene и решение по Hebeanlage ДО названия
цены, а не после того, как клиент уже услышал цену "просто WC", (м) для
наружного оборудования, влияющего на соседей шумом (сценарий 16 —
тепловой насос) — измеримые параметры (расстояние до окон соседей,
паспортный уровень звуковой мощности), зафиксированные ДО монтажа, а не
общие слова "по норме" постфактум, (н) для работ, выполняемых на стыке
двух специализаций с процедурным (не физическим) скрытым дефектом
(сценарий 17 — тёплый пол и укладка покрытия) — документ, который
передаётся от одного исполнителя другому и блокирует следующий шаг
рабочего процесса до своего завершения, а не просто хранится как
архивная запись.

Отдельно, вне логики споров: **для электромонтажных работ документ
приложения должен уметь нести протокол измерений Erstprüfung
(DIN VDE 0100-600) и обзорную схему** — по действующей ATV DIN
18382:2023-09 это часть документации приёмки, а сам протокол является
единственным доказательством того, что проверка вообще проводилась. Это
на сегодня единственная специализация, где эта обязанность закреплена
прямо в тексте самой ATV (договорной слой). У сантехники (см. выше)
найден содержательно тот же механизм — обязательный протокол опрессовки
до закрытия трубы, подкреплённый реальным судебным делом (сценарий
14) — но источник обязательности сегодня подтверждён только на уровне
отраслевого технического правила (DIN EN 806-4/ZVSHK), не текста самой
ATV DIN 18381, поэтому не уравниваю два случая по силе источника, хотя
продуктовый вывод (форсировать протокол) для обоих одинаков.

Не просто "фото+подпись", а структура, закрывающая конкретно эти 17
сценариев.

## Разбор конкурентов — конкретные жалобы (не выдумано)

- **PlanRadar**: нет экспорта в CAD/GIS, нельзя сделать протокол со
  списком участников, отчёты "слишком длинные для протокола", нет
  сортировки по участку/дате, тикеты нельзя переставить местами, съедает
  много мобильного трафика.
- **Capmo**: нет фильтра тикетов между проектами, документы/фото нельзя
  хранить централизованно (в отличие от планов), синхронизация
  "зависает", интерфейс "слишком много места под мало информации".
- **Craftboxx**: сам вендор признаёт — нет Angebot/Rechnung/бухгалтерии
  из коробки, **нет формального инструмента Aufmaß (замеров)**, нет
  GAEB/AVA модуля, нет DATEV, удалённый контент не восстановить самому.
- **Nachtragsheld/Meisterwerk**: почти нет отзывов вообще — тонкий след,
  сам по себе говорит о возможности выделиться реальной проверенностью.

Каждый день (не 5 минут) агент должен:
1. Проверять логику каждого добавленного раздела — не просто "звучит
   правильно", а обоснование "почему так", со ссылкой на стандарт/кейс.

   (Lüftungstechnik) — последняя из четырёх названных владельцем явно
   специализаций (electrical/plumbing/HVAC/heating), приоритет выше,

   позиции полного каталога 65 ATV выше).

   встраивать найденные проблемы как решения в этом документе.
4. Продумывать поведение заказчика (Auftraggeber) — новые сценарии
   споров/возражений в немецких реалиях, не только 17 уже найденных.
5. Обновлять этот файл на месте (не плодить "## Обновление от даты" —
   переписывать раздел, если новое находка меняет прежний вывод).
