# Кейсы 3+4 — Klettern Hub: контент-сайт + конвертер грейдов

Статус: контент и инструмент готовы, ждут деплоя владельцем (одна и та же
инфраструктура на двоих).

---

## 1. Что делаем

Один мини-сайт "Klettern Hub" из двух связанных частей:
- **Контент-сайт (кейс 3)** — справочные статьи о скалолазании на немецком
  для DACH-аудитории: "Kletter-Schwierigkeitsgrade erklärt" (готова),
  "Boulder-Grade: V-Scale vs. Fontainebleau erklärt" (готова),
  "Erste Kletterhalle: was Anfänger wissen müssen" (готова).
- **Инструмент (кейс 4)** — рабочий автономный конвертер грейдов
  (French/YDS/UIAA/British/Ewbank + V-Scale/Fontainebleau), без сервера,
  без базы данных.
Обе части ссылаются друг на друга и на кейсы 1-2 (Etsy-магазин,
принтаблы) — статья объясняет, инструмент считает, оба ведут к магазину.

## 2. Откуда берём (ниша, обоснование выбора)

Рассмотрено 3 варианта, выбор обоснован:
1. ~~"Kletterschuhe für Anfänger" (обзоры снаряжения)~~ — отклонено:
   заняты крупными игроками (Bergzeit, Bergfreunde, Globetrotter) с
   многолетним SEO-весом, новому сайту не пробиться в разумные сроки.
2. **"Kletter-Schwierigkeitsgrade erklärt" (объяснение систем грейдов)**
   — выбрано: подтверждённый спрос (много англоязычных конвертеров грейдов,
   мало немецкоязычных объясняющих статей), низкая коммерческая
   конкуренция, прямая синергия статья↔инструмент.
3. "Climbing gift ideas" — не первая тема, но хороший кандидат на 2-3
   статью (синергия с кейсами 1-2), нет причины возвращаться/делиться так
   же сильно, как у справочного контента.

## 3. Где размещаем (канал/хостинг)

**GitHub Pages на этом же репозитории** — не новый аккаунт (репозиторий
уже существует), просто включить функцию в настройках. Автодеплой уже
настроен: `.github/workflows/deploy-pages.yml` публикует только публичные
файлы (content-site + grade-tool; внутренние аудиты и платный PDF кейса 2
не публикуются) при каждом пуше в main.

Опционально — свой домен `klettergrade.de` (~€4-5/год) поверх того же
бесплатного хостинга вместо поддомена `username.github.io` — лучше для
немецкого SEO и для будущей заявки в Amazon Partnernet. Полное обоснование
и готовые кандидаты доменных имён: `domain-plan.md`. Это ПЛАН, не куплено.

## 4. Как двигаются деньги

Прямых денег в этой связке нет — сайт и инструмент бесплатны для
посетителя, монетизация непрямая (см. п.6). Расход только на домен
(опционально, см. п.3), проводит владелец сам.

## 5. Монетизация / юнит-экономика

- **Сейчас**: ссылки в футере на Etsy-магазин (кейс 1) и принтаблы
  (кейс 2) — бесплатный трафик-мост между всеми кейсами, с UTM-метками
  для отслеживания реальных переходов после деплоя.
- **Позже**: Amazon Partnernet (партнёрские ссылки на снаряжение —
  скальники, мешки для магнезии) — НЕ сейчас. Одобрение Partnernet
  требует 3 квалифицированные продажи за 180 дней — подавать заявку без
  трафика бессмысленно, дождаться первых реальных посетителей после
  деплоя.

## 6. Продвижение

Прямого продвижения нет — расчёт на органический поисковый трафик
(Google) по статьям + переходы из кейсов 1-2 (Instagram, магазин). Честно:
SEO с нуля на новом домене — месяцы, не недели (см. прогноз ниже).

## 7. Регистрация

Не требуется новых аккаунтов для хостинга (используется существующий
GitHub-репозиторий) — только включить GitHub Pages в настройках (2 клика,
см. п.9). Домен (опционально) — отдельная небольшая покупка, не
регистрация аккаунта.

## 8. Честный прогноз

Сайт ещё не задеплоен — трафика нет. После деплоя: SEO на новом домене
без обратных ссылок реалистично даёт первый органический трафик через
**месяцы, не недели** — в рамках 4-месячного срока проекта это скорее
задел на будущее, чем источник дохода сейчас. Прямого дохода эта пара
кейсов не приносит — её роль в портфеле — приводить трафик в кейсы 1-2,
и это тоже не быстрый эффект.

## 9. Что нужно от владельца (пакетом)
1. **Включить GitHub Pages**: Settings репозитория → Pages → Source:
   "GitHub Actions" → Save. 2 минуты, ничего создавать не нужно, сайт
   появится на `<username>.github.io/<repo>/` после следующего пуша.
2. (Опционально) **Домен** `klettergrade.de` (~€4-5/год) — см. `domain-plan.md`
   для деталей и альтернативы `kletternhub.de`. Не обязательно — п.1 уже
   даёт рабочий бесплатный сайт.
