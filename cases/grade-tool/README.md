# Кейс 4 — Climbing Grade Converter (микро-инструмент)

## Продукт
`index.html` — рабочий, автономный (без зависимостей, без бэкенда)
конвертер грейдов скалолазания: маршруты (French/YDS/UIAA/British/Ewbank)
и боулдеринг (V-Scale/Fontainebleau). Проверено headless-рендером —
переключение вкладок и выбор грейда работают, значения совпадают с
опубликованными таблицами соответствий.

## Почему этот инструмент (обоснование)
- **Синергия с кейсами 1 и 2**: та же аудитория (скалолазы), тот же бренд
  ROUTELINEWEAR — футер инструмента ссылается на Etsy-магазин, инструмент
  работает как бесплатный лид-магнит/визитка для остального портфеля.
- Веб-поиск подтвердил спрос (много существующих конвертеров грейдов), но
  большинство — перегружены рекламой/платными приложениями; чистый быстрый
  инструмент без баннеров — реальная альтернатива.
- $0 бюджет: чистый HTML/CSS/JS, без сервера, без базы данных.

## Хостинг (бесплатно, требует 5 минут владельца)
Не задеплоено — репозиторий приватный. Варианты (владелец выбирает и
включает, агент не создаёт новых аккаунтов):
1. GitHub Pages на этом или отдельном публичном репозитории — бесплатно,
   поддомен `<username>.github.io`.
2. Netlify/Vercel free tier — drag-and-drop `index.html`, бесплатный
   поддомен, уже существующий тип сервиса (не требует явного одобрения
   как "новый аккаунт" в духе Gumroad, но всё равно создание аккаунта —
   см. "Needs owner approval" в PORTFOLIO.md).
