# Продвижение через видео/Reels — проверенный план (2026-08-11)

Правка после обратной связи владельца: раньше сказал "не могу профессиональное
видео" не проверив реальные инструменты — это была непроверенная информация.
Проверил. Реально можно, бесплатно на старте, с потолком качества, который
честно описан ниже. Два независимых решения, не одно.

## Роль-агент: "видео-продюсер" (виртуальная, см. устав)
Собирает: сценарий → отбор кадров от поставщика → монтаж с субтитрами/
трендовой музыкой → (опционально) аватар-презентёр поверх. Инструкции ниже
покрывают весь процесс, не только "придумай идею".

## Решение №1 — без аватара, монтаж из готовых материалов поставщика
1. **CJ Dropshipping бесплатно даёт готовые фото/видео товара** по каждому
   SKU (раздел "Promote Products with Videos" в личном кабинете) — реальный,
   подтверждённый источник кадров, не нужно снимать самим.
2. Монтаж вертикального ролика с трендовыми субтитрами/музыкой —
   **Captions app** (есть бесплатный тариф, без вотермарки — единственный
   из проверенных с таким условием) или **InVideo AI** (бесплатно ~10 мин
   генерации/неделю, 720p, с вотермаркой на бесплатном тарифе).
3. Формат: хук первые 2 сек (проблема — "поводки запутались?") → кадр
   товара от CJ → решение → CTA на магазин.

## Решение №2 — с AI-аватаром (говорящий персонаж)
1. **HeyGen** — бесплатно 3 видео/мес, до ~1 мин, 1080p, но с вотермаркой
   на бесплатном тарифе. Платно от $29/мес без вотермарки, с клонированием
   голоса.
2. Сценарий пишет агент (роль "копирайтер"), аватар озвучивает.
3. Хуже подходит для формата "тренд Reels" (больше похоже на explainer),
   лучше как "интро/CTA" поверх материалов из решения №1, чем как
   отдельный ролик целиком.

## Честный потолок качества на $0
Оба решения реально дают смотрибельный, не "самопальный" результат —
но с вотермаркой (кроме Captions) и с лимитом по количеству роликов/мес,
которого не хватит на ежедневную публикацию. Для регулярного постинга без
вотермарки в 1080p — реалистичный бюджет **$20-30/мес** (InVideo Plus или
HeyGen Creator), когда объём продаж это оправдает. $0 — это тариф для
теста гипотезы, не для масштаба.

Дополнительно у CJ есть платная услуга кастомной съёмки конкретного товара
(запрос → квота за ~2 рабочих дня → съёмка) — вариант на будущее, если
бесплатные материалы поставщика не подойдут по ракурсу/стилю.
