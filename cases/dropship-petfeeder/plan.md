# Кейс 5 — Дропшиппинг: автокормушки для животных (eBay.de + CJ Dropshipping)

## [ПЛАН] — предложение, ничего ещё не создано/куплено

Это прямая реализация схемы, предложенной владельцем: покупатель платит
на нашей витрине → система поставщика сама списывает деньги (с карты
владельца, привязанной у поставщика) и отправляет товар по адресу
покупателя — без ручной работы по каждому заказу.

## Почему не Etsy (см. "Принцип сквозной цепочки" в уставе)
Серийный (не handmade) товар на Etsy плохо ранжируется и рискует нарушить
политику площадки. Канал — **eBay.de**, культурно и алгоритмически подходит
для обычных потребительских товаров, плюс доступ уже есть через Gewerbe.

## Ниша: автоматические кормушки/поилки для животных
- Пет-товары — маржинальная категория (в среднем ~64% валовая маржа по
  индустрии), при этом обычные аксессуары (поводки, игрушки) перенасыщены,
  а автокормушки/поилки/устройства для мониторинга здоровья — заметно менее
  конкурентная под-ниша.
- Избегаем GPS-трекеров с SIM-картой/подпиской — плохо подходит для
  соло-дропшиппера без инфраструктуры подписок.
- Источник: см. Sources ниже (Dropified, TrueProfit, 2026).

## Поставщик: CJ Dropshipping
- Есть **нативная интеграция с eBay** (My CJ → Authorization → Add Store →
  eBay) — синхронизация листингов, остатков, автоматическая передача
  трек-номера в eBay. Готовый Shopify-магазин НЕ обязателен для старта.
- **Критично**: брать товар именно со склада CJ в **Германии/ЕС**, не из
  Китая напрямую — с 2026 ЕС отменяет беспошлинный порог €150, прямые
  посылки из Китая получат дополнительно 15-30% к себестоимости и хуже
  переносят гарантии/сроки доставки (15-45 дней вместо 3-7 из ЕС-склада).
  Это влияет на рейтинг продавца на eBay, не только на маржу.
- Дропшиппинг через легитимного B2B-поставщика (CJ) разрешён политикой
  eBay — запрещён именно "retail arbitrage" (перепродажа с Amazon/Walmart
  без оптовых отношений). Упаковка/накладные должны быть от лица владельца,
  не CJ/Китая.

## Юнит-экономика (честный расчёт, не по мотивам "накрутки")
| Статья | Сумма |
|---|---|
| Себестоимость товара (ЕС-склад CJ) | ~€18 |
| Доставка CJ (ЕС → покупатель) | ~€4 |
| **Итого себестоимость** | **~€22** |
| Цена на eBay.de (конкурентно к Amazon €35-60) | €44.99 |
| Комиссия eBay.de (категория ~11-12% + €0.45/заказ, 2026) | ~€5.85 |
| **Чистая выручка после комиссии eBay** | **~€39.14** |
| **Маржа до возвратов** | **~€17.14** |
| Резерв на возвраты/брак (~€2) | -€2 |
| **Реальная чистая прибыль с продажи** | **€13-15 (~30% от цены)** |

Комиссия эквайринга у eBay Managed Payments уже встроена в итоговую
комиссию, отдельной строкой не идёт (проверить в личном кабинете eBay.de
после регистрации магазина — цифра ориентировочная).

## Честный прогноз объёма продаж
Новый продавец без отзывов на eBay ранжируется ниже устоявшихся конкурентов
даже при верной цене — реалистичный разгон **2-3 месяца** до значимой
прибыли. Месяц 1-2 при верно выбранном товаре: ориентировочно **5-15
продаж/мес** → €200-700 выручки, **€70-225 чистыми** до рекламы. Это не
"жить на это", а валидация + накопление отзывов. Масштаб (30+ продаж/мес)
обычно требует истории отзывов и/или платного продвижения.

## Что нужно от владельца (пакетом, не по одному)
1. Зарегистрировать аккаунт CJ Dropshipping (агент не создаёт аккаунты).
2. Привязать способ оплаты у CJ (карта, с которой будут списываться
   заказы — это и есть механизм "агент определяет адрес, система сама
   списывает и отправляет", без ручного участия по каждому заказу).
3. Подключить eBay.de магазин к CJ через встроенную интеграцию (My CJ →
   Authorization → Add Store → eBay) — после подключения синхронизация
   заказов полностью автоматическая.
4. Подтвердить выбор конкретной модели автокормушки на складе CJ в ЕС
   (агент подберёт 2-3 конкретных SKU с ссылками на следующем шаге, после
   одобрения направления).

## Следующий шаг агента (после одобрения направления)
Подобрать 2-3 конкретные модели автокормушек на ЕС-складе CJ (ссылки,
фото, спецификации), написать листинг для eBay.de (заголовок, описание,
характеристики, конкурентный анализ цен), подготовить всё до состояния
"нажать кнопку" — останется только физически создать/привязать аккаунты.

## Конкретика по запросу владельца (2026-08-11): что/кому/почему/как

**Что именно** — фидер класса "5L, WiFi+приложение, БЕЗ камеры" (расписание
кормления, датчик низкого уровня/засора корма). Не абстрактная "кормушка":
- Премиум (с камерой, напр. PETLIBRO Granary Camera / Catit PIXI Smart):
  €106-170 — толкучка топ-брендов, дороже.
- **Наш выбор — средний класс (WiFi+приложение, без камеры)**: реально
  продаётся на eBay.de прямо сейчас за €42.98-47.98 — наша цена €44.99
  не выдумана, а взята из реального рынка.
- Базовый (только таймер, без WiFi, напр. Cat Mate C500/Trixie): €22-33 —
  commoditized, гонка по дну, не наш вариант.
Контекст рынка (Amazon.de "Futterautomat Katze"): ~€1.4M/год категория,
средняя цена €41.91, топ-5 брендов держат 56%, 37% рынка открыто новым
продавцам.

**Кому именно** — не "владельцы питомцев" вообще, а люди, которые уезжают
на 2-3 дня (выходные/командировка) и боятся оставить животное без
присмотра. Доказуемо: вопрос "сколько можно оставить кота одного с
автокормушкой" — регулярный запрос в ветеринарных блогах и форумах,
устойчивый ответ "24-48ч норма, 72ч предел". Это конкретнее и
проверяемее, чем "забота о рационе" или "мультикошачьи семьи".

**Почему эта модель, не другая** — датчик блокировки/остатка корма прямо
отвечает на главный страх покупателя ("а вдруг заклинит, пока меня нет") —
у базовых таймеров такого нет, у камерных моделей это есть, но они дороже
и рынок там теснее. Позиционирование листинга — не "умная кормушка", а
"безопасно оставь кота на выходные".

**Как физически работает цепочка** (реальные точки, где нужны руки
владельца, без прикрас — до подключения платного синхронизатора вроде
DSers/AutoDS при появлении объёма):
1. Покупатель платит на eBay.de — автоматически
2. Заказ → **вручную** переносится в форму заказа CJ (адрес, SKU)
3. CJ списывает деньги с привязанной карты, склад в ЕС (DE/NL/PL) собирает
   и упаковывает — автоматически
4. Доставка курьером (DHL/DPD/GLS) 2-5 дней по ЕС — автоматически
5. Трек-номер → **вручную** вставляется в eBay
6. Возврат/брак — приходит владельцу как продавцу, разбирается через
   политику CJ — **вручную**

## Регистрация и одобрение — полный чек-лист (2026-08-11, чтобы не упереться в конце)

### CJ Dropshipping
- Регистрация — просто email+пароль, без документов/ID для старта.
- API/интеграция с eBay — доступна всем, без платного тарифа, без порога
  по обороту (по официальной документации). Один нюанс: **название
  магазина в CJ должно точно совпадать с eBay user ID**, иначе привязка
  не пройдёт.
- **Поправка к автоматизации**: не нужен кастомный API-скрипт — у CJ есть
  готовый встроенный коннектор (My CJ → Authorization → Add Store → eBay),
  который сам синхронизирует заказы, остатки и трек-номера. Моя более
  ранняя идея "напишу скрипт-синхронизатор" была избыточной.

### eBay.de — коммерческий (gewerblich) продавец
Нужно для регистрации:
- Название и адрес бизнеса, юр. форма (Einzelunternehmen — то, что уже
  есть через Gewerbe)
- **USt-IdNr. (VAT ID)** — обязателен с июля 2021 даже для Kleinunternehmer
  по §19 (сама льгота по НДС не освобождает от получения номера)
- Полная верификация личности продавца (документы компании, ID
  представителя) — это реальная точка задержки, на форуме eBay.de есть
  живые жалобы на "Verifizierung Unternehmensangaben — Massive Probleme"
- Банковский счёт **именно бизнес-типа** (не личный) под eBay Managed
  Payments
- **Стартовый лимит продаж** для новых коммерческих продавцов — обычно
  ~10 товаров/€500 в месяц, автоматически растёт после ~90 дней чистой
  работы (или по ручному запросу раньше)

### Про кастомный API (уже не нужен, но на будущее)
Если позже понадобится не встроенный коннектор CJ, а прямой eBay API —
это ОТДЕЛЬНОЕ одобрение от аккаунта продавца (eBay Developers Program),
продакшн-доступ не гарантирован автоматически. Раз встроенной интеграции
CJ достаточно для старта — не требуется прямо сейчас.

### Реальные причины блокировки аккаунта (что НЕ делать)
Не сама автоматизация — а: долгие/нестабильные сроки доставки (отсюда
критично важен именно ЕС-склад CJ, не Китай), высокий процент
дефектов/жалоб "товар не пришёл", и жалобы по товарным знакам (VeRO) на
брендированные товары. У нас все 5 товаров — небрендированные аксессуары
для животных, риск VeRO низкий.

### Вывод
Никаких скрытых стоп-факторов не нашёл — регистрация реальна и укладывается
в схему, аналогичную уже работающей связке Etsy+Printful (кейс 1): один
маркетплейс (eBay вместо Etsy) + один поставщик-фулфилмент (CJ вместо
Printful), тот же принцип "покупатель платит → поставщик сам списывает и
шлёт". Главные не-технические требования — VAT ID и полная верификация
личности продавца у eBay, это делает владелец сам.

## 2 аккаунта или 1? (ответ на вопрос владельца)
Всегда **2 отдельных аккаунта**, это не вопрос выбора:
- **CJ Dropshipping** — поставщик/склад/фулфилмент (аналог Printful в кейсе 1)
- **eBay.de продавец** — витрина/канал продаж (аналог Etsy в кейсе 1)
Они не заменяют друг друга, а соединяются через встроенный коннектор
(см. выше). eBay-аккаунт — новый, отдельный от текущего Etsy-магазина
ROUTELINEWEAR (разные площадки, разная аудитория, смешивать не нужно).

## 5-й товар (по запросу владельца): двойной поводок без запутывания

  double dog leash coupler", обычно с вертлюгом (360° swivel), даёт собакам
  крутиться друг вокруг друга без перехлёста поводков.
- Реальные цены рынка: eBay.de €14.99-25.95, Fressnapf.de €29.99
  (растяжимый, verhedderungsfrei), Zooplus.de от €19.79.
- **Наша цена: €16.99-19.99** — ниже Fressnapf/Zooplus, в рынке eBay.de.
- Кому: хозяева двух собак одновременно, выгульщики/петситтеры, активные
  хозяева (бег/поход с двумя собаками), уставшие от запутывающихся поводков.
- Позиционирование: "Два пса, один поводок, никакой путаницы —
  вращающийся адаптер-двойник для спокойных прогулок."

## Продвижение (владелец спросил "как продвигать")
Без бюджета на старте органика почти не работает для нового магазина без
истории — придётся либо небольшой платный трафик (eBay Promoted Listings,
% от продажи, без риска фикс. расходов — оплата только за клик/продажу),
либо соцсети. Если соцсети — см. отдельный раздел ниже, важная оговорка
по видео.

## Про "профессиональные Reels/видео" — честная оговорка
Не могу обещать по-настоящему профессиональное видео из ничего: нет
инструмента генерации видео, и пока нет реального товара в руках (не
куплен), значит нет реальных кадров продукта. Что реально могу: сценарии/
раскадровки для роликов, тексты субтитров/подписей, структуру рекламных
креативов (хук-проблема-решение), подбор референсов конкурентов. Как
только появятся реальные фото/видео от CJ (у поставщиков обычно есть
готовые маркетинговые фото/видео товара) или сам товар в руках — можно
довести до реально презентабельного результата. Обещать "профессиональное
видео" на пустом месте было бы нечестно.
