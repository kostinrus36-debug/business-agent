# Кейс 5 — подбор SKU у CJ Dropshipping (внешняя разведка, без входа в аккаунт)

Статус: ЧЕРНОВОЙ подбор кандидатов, ни один SKU не выбран окончательно.
Цель документа — сузить круг поиска перед тем, как владелец (или агент
через будущий доступ к дашборду) будет выбирать точный SKU внутри CJ.

## Важная оговорка про метод

У агента нет логина ни в CJ, ни в eBay, и нет браузерного инструмента —
только WebSearch/WebFetch по публичному вебу. Дополнительное
ограничение, выявленное в процессе: **весь домен cjdropshipping.com
(включая поддомены blog. и eur.) блокируется на уровне сетевого
egress-прокси этой среды** — прямой `curl` и WebFetch оба возвращают
403/EGRESS_BLOCKED при попытке открыть конкретную страницу товара.
Это не ограничение доступа CJ (не login wall), а политика прокси в
этой рабочей среде — значит, даже название/цену/склад конкретного SKU
нельзя вытащить напрямую с страницы товара, только через то, что Google
успел проиндексировать в сниппете поиска (WebSearch). Заголовки страниц
и обрывки текста — да, полная страница с ценой и полем "склад" — нет.

**Вывод:** ниже — только то, что реально нашлось через индексацию
Google (WebSearch), с честной пометкой, что именно не подтверждено.
Цена и признак "склад в ЕС" по конкретному SKU **не проверяемы снаружи
в принципе** (CJ не публикует остатки по складам в открытых
сниппетах/метатегах) — это придётся смотреть только изнутри дашборда
CJ (My CJ → поиск товара → фильтр по складу), что не входит в
возможности агента без логина.

## Итог: что проверено снаружи, что нужно проверять в дашборде CJ

| Товар | CJ-товар найден внешне | Цена | EU-склад | Итог |
|---|---|---|---|---|
| 1. WiFi-кормушка | 1 кандидат (неоднозначный) | нет | нет | требует проверки в дашборде |
| 2. Поилка/фонтанчик | 1 кандидат (ёмкость не совпадает) | нет | нет | требует проверки в дашборде |
| 3. Кормушка с камерой | 0 кандидатов | нет | нет | искать заново внутри CJ |
| 4. Базовая таймер-кормушка | тот же кандидат, что п.1 (неоднозначно) | нет | нет | требует проверки в дашборде |
| 5. Двойной поводок | 0 кандидатов | нет | нет | искать заново внутри CJ |

**Честно про степень проверяемости:** из 5 категорий внешний поиск дал
хоть какую-то зацепку (URL товарной карточки CJ) только для 2 из 5, и
ни для одной из них не удалось подтвердить ни цену, ни склад — эти
данные CJ не публикует в индексируемом виде (страница товара требует
JS-рендеринга и/или входа для показа цены/остатков по складам, плюс сам
домен недоступен для WebFetch в этой среде). Единственное, что внешний
поиск даёт надёжно — это рыночные цены конкурентов (Amazon/eBay/Chewy)
по аналогичным товарам, которые подтверждают, что ценовые ориентиры
плана (`plan.md`, п.1) соответствуют реальному рынку, но это не то же
самое, что подтверждение SKU/цены/склада у CJ.

**Что нужно сделать внутри дашборда CJ (задача для владельца или для
агента, когда появится доступ):**
1. Зайти в My CJ → поиск/каталог → искать по каждой из 5 категорий с
   фильтром склада = Europe (Germany/Netherlands/Poland — как указано в
   `plan.md`, п.2).
2. Для найденных карточек проверить: точную ёмкость/спецификацию (WiFi
   да/нет, камера да/нет, ёмкость в литрах), актуальную закупочную
   цену, реальный остаток на EU-складе (не "на бумаге", а физически in
   stock — CJ иногда показывает склад как опцию, даже если товара там
   physически нет, это известная проблема дропшиппинга через CJ).
3. Отдельно уточнить для категории 3 (камера) и 5 (поводок) — по ним
   вообще нет ни одной внешней зацепки, начинать поиск с нуля прямыми
   запросами в поиске CJ ("pet feeder camera", "double dog leash
   coupler", "no tangle leash").
4. Смотреть на карточки как на "родительский товар с вариантами" — CJ
   часто прячет разные версии (с WiFi / без WiFi, разные ёмкости) под
   одной карточкой в выпадающем списке вариантов, это объясняет, почему
   один и тот же внешний URL (п.1/п.4) мог оказаться и WiFi-, и
   базовой моделью одновременно.

## 6. Новый кандидат (2026-08-25) — не электроника, можно опубликовать раньше остальных

Мандат владельца (2026-08-21, plan.md) — регулярно искать бестселлеры.
Веб-поиск (2026-08-25) по трендам pet-дропшиппинга 2026 называет
**лизательные/снаффл-маты (lick mats / snuffle mats), охлаждающие
коврики, очистители лап (paw cleaner cups)** среди топ-бестселлеров —
не с одного сайта, тот же набор независимо повторяют Zendrop и
Dropified. Источники: [zendrop.com](https://www.zendrop.com/blog/dropshipping-pet-products/),
[dropified.com](https://www.dropified.com/blog/best-pet-products-to-dropship-in-2026-15-items-pet-owners-are-buying-right-now/).

**Почему это стратегически интереснее просто "ещё один товар":** 3 из
текущих 5 товаров — электроника (WiFi-кормушка, кормушка с камерой,
поилка-помпа) и упираются в WEEE-регистрацию, которая ещё не начата
(`registration-followups.md`). **Лизательный коврик и очиститель лап —
не электроника**, не требуют WEEE/Batterie-Register, только LUCID
(упаковка, п.1 пакета одобрения в PORTFOLIO.md) — то есть теоретически
могут быть опубликованы раньше остальных, сразу после LUCID, не
дожидаясь WEEE.

**Добавить в шаг поиска внутри дашборда CJ** (тот же процесс, что для
остальных 5 — см. "Что нужно сделать внутри дашборда CJ" выше): искать
"pet lick mat", "dog snuffle mat", "pet paw cleaner cup" с фильтром
Ship From: Europe, подтвердить цену/склад так же, как для остальных
позиций. Внешне (WebSearch/WebFetch) конкретный CJ SKU не проверить —
тот же блок домена, что и для остальных 5 категорий (см. "Важная
оговорка про метод" в начале файла).
