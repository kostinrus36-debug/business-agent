# Идея для нового чата: 3D-приложение для технологических труб

Мобильное приложение для трёхмерной прокладки технологических труб:

- По фото участков определяет диаметры труб
- Переносит все данные в проект (3D-модель) с точностью до миллиметра
- Указывает температуры сред, которые протекают по трубам
- Всё в соответствии с европейскими нормами/тех. документацией — нужна
  встроенная библиотека стандартов
- Целевая аудитория: организации, обслуживающие промышленные объекты
  нефтегазовой отрасли — в частности подрядчики/обслуживающие организации
  **British Petroleum (BP)**

Это отдельная, технически сложная задача (точные замеры по фото — это
фотограмметрия/компьютерное зрение, нетривиально), не связана с проектом
бизнес-инкубатора (~/business-agent). Обсуждать отдельно, с нуля.
